## Руководство для организатора

### Первые шаги

#### 1. Вход в систему

1. Откройте браузер и перейдите на адрес системы: `https://rgsystem.local`
2. Введите ваш email и пароль
3. Нажмите кнопку **"Войти"**

> **Примечание:** Если вы забыли пароль, нажмите "Забыли пароль?" и следуйте инструкциям для восстановления.

#### 2. Создание нового соревнования

**Путь:** Главная → Соревнования → Создать новое

**Шаги:**

1. Нажмите кнопку **"Создать соревнование"**

2. Заполните основную информацию:
   - **Название:** Например, "Кубок Москвы 2025"
   - **Город:** Москва
   - **Место проведения:** СК «Олимпийский»
   - **Адрес:** Олимпийский проспект, 16
   - **Дата начала:** 15.03.2025
   - **Дата окончания:** 17.03.2025

3. Выберите параметры соревнования:
   - **Уровень:** Национальный / Региональный / Международный
   - **Формат:** Индивидуальное многоборье / Финалы в отдельных видах / Групповые упражнения
   - **Возрастные категории:** Юниоры, Юноши, Взрослые
   - **Предметы:** Скакалка, Обруч, Мяч, Булавы, Лента

4. Настройте дополнительные параметры:
   - ✅ Разрешить публичный просмотр результатов
   - ✅ Включить живое обновление оценок
   - ✅ Включить видеообзор выступлений (опционально)
   - **Максимум спортсменов от одного клуба:** 10

5. Нажмите **"Создать"**

**Результат:** Соревнование создано в статусе "Черновик"

---

#### 3. Регистрация спортсменов

**Путь:** Соревнования → [Название соревнования] → Участники → Добавить

**Два способа регистрации:**

##### Способ 1: Индивидуальная регистрация

1. Нажмите **"Добавить спортсмена"**
2. Заполните данные:
   - **Имя:** Анна
   - **Фамилия:** Иванова
   - **Отчество:** Сергеевна
   - **Дата рождения:** 20.05.2008
   - **Клуб:** СДЮШОР Динамо
   - **Тренер:** Мария Петрова
   - **Спортивный разряд:** КМС
3. Выберите возрастную категорию: Юниоры
4. Выберите предметы: Скакалка, Обруч, Мяч, Булавы, Лента
5. Присвойте стартовый номер: 45
6. Нажмите **"Зарегистрировать"**

##### Способ 2: Массовая регистрация (Excel/CSV)

1. Нажмите **"Импорт из файла"**
2. Скачайте шаблон Excel
3. Заполните данные спортсменов в шаблоне
4. Загрузите заполненный файл
5. Проверьте данные в предварительном просмотре
6. Нажмите **"Импортировать"**

**Результат:** Спортсмены зарегистрированы на соревнование

---

#### 4. Формирование групп и расписания

**Путь:** Соревнования → [Название] → Группы → Создать группу

**Шаги:**

1. Нажмите **"Создать группу"**
2. Укажите параметры:
   - **Название:** Группа 1 - Юниоры (Скакалка)
   - **Возрастная категория:** Юниоры
   - **Предмет:** Скакалка
   - **Дата:** 15.03.2025
   - **Время начала:** 10:00
   - **Количество спортсменов:** 18

3. Добавьте спортсменов в группу:
   - Выберите из списка зарегистрированных
   - Или система автоматически распределит по категориям

4. Нажмите **"Создать группу"**

5. **Формирование стартового протокола:**
   - Нажмите **"Генерировать стартовый протокол"**
   - Выберите метод:
     - **Случайный** (рекомендуется для честности)
     - **По рейтингу** (сильнейшие в конце)
     - **Вручную** (ручная расстановка)
   - Нажмите **"Применить"**

**Результат:** Группа создана, стартовый протокол готов

---

#### 5. Назначение судейской бригады

**Путь:** Соревнования → [Название] → Судьи → Назначить бригаду

**Шаги:**

1. Выберите группу: "Группа 1 - Юниоры (Скакалка)"

2. **D-панель (Сложность):**
   - Нажмите **"Добавить D-панель"**
   - Выберите 4 судей категории Brevet 3+:
     - Елена Соколова (Brevet 3) - позиция 1
     - Ирина Кузнецова (Brevet 3) - позиция 2
     - Наталья Смирнова (Brevet 4) - позиция 3
     - Светлана Морозова (Brevet 3) - позиция 4

3. **E-панель (Исполнение):**
   - Нажмите **"Добавить E-панель"**
   - Выберите 6 судей категории Brevet 2+:
     - Татьяна Волкова (Brevet 3) - позиция 1
     - Ольга Лебедева (Brevet 2) - позиция 2
     - ... и т.д.

4. **Линейные судьи:**
   - Добавьте 4 судей для контроля границ ковра

5. Нажмите **"Сохранить бригаду"**

**Результат:** Судейская бригада назначена на группу

---

#### 6. Активация соревнования

**Путь:** Соревнования → [Название] → Настройки → Активировать

**Проверка перед активацией:**

- ✅ Все группы созданы
- ✅ Все спортсмены зарегистрированы
- ✅ Стартовые протоколы сформированы
- ✅ Судейские бригады назначены
- ✅ Расписание утверждено

**Шаги:**

1. Перейдите в раздел **"Настройки"**
2. Проверьте все данные
3. Нажмите кнопку **"Активировать соревнование"**
4. Подтвердите действие

**Результат:** Соревнование переведено в статус "Активное", начинается судейство

---

#### 7. Мониторинг хода соревнований

**Путь:** Соревнования → [Название] → Панель управления

**Что можно видеть:**

- **Текущее выступление:** Кто сейчас на ковре
- **Статистика оценок:** Сколько оценок выставлено/подтверждено
- **Расписание:** Соблюдение временных рамок
- **Проблемы:** Предупреждения и ошибки (если есть)

**Действия:**

- Просмотр оценок в реальном времени
- Разрешение спорных ситуаций (запрос главного судьи)
- Корректировка расписания (если необходимо)
- Экспорт промежуточных результатов

---

#### 8. Завершение соревнования

**Путь:** Соревнования → [Название] → Завершить

**Шаги:**

1. Убедитесь, что все выступления оценены
2. Проверьте итоговые протоколы
3. Нажмите **"Завершить соревнование"**
4. Система автоматически:
   - Зафиксирует все результаты
   - Сформирует итоговые протоколы
   - Отправит уведомления участникам

5. **Экспорт результатов:**
   - Нажмите **"Экспорт"**
   - Выберите формат: Excel / PDF / CSV
   - Скачайте файл

**Результат:** Соревнование завершено, результаты зафиксированы

### Частые вопросы организатора

**Q: Можно ли изменить соревнование после активации?**
A: Некоторые данные (спортсмены, расписание) можно изменять. Основные параметры (название, даты, формат) изменить нельзя.

**Q: Как добавить спортсмена, который опоздал с регистрацией?**
A: Перейдите в Участники → Добавить спортсмена. Если группы уже сформированы, спортсмена нужно добавить в соответствующую группу вручную.

**Q: Что делать, если судья не может работать?**
A: Перейдите в раздел Судьи → выберите группу → Заменить судью → выберите замену.

**Q: Можно ли отменить соревнование?**
A: Да, в статусе "Черновик" соревнование можно удалить. Активное соревнование удалить нельзя, но можно перевести в статус "Отменено".

## Руководство для главного судьи

### Роль и обязанности

Главный судья отвечает за:
- Контроль работы судейских бригад
- Валидацию и подтверждение оценок
- Разрешение спорных ситуаций
- Обеспечение соблюдения правил FIG

### Первые шаги

#### 1. Вход в систему

1. Откройте `https://rgsystem.local`
2. Войдите с учетными данными главного судьи
3. Вы попадете на **Панель главного судьи**

---

#### 2. Просмотр назначенных соревнований

**Путь:** Главная → Мои соревнования

**Что видно:**
- Список соревнований, где вы назначены главным судьей
- Статус каждого соревнования
- Даты и время проведения
- Количество спортсменов и судей

**Действия:**
- Нажмите на соревнование для перехода к панели управления

---

#### 3. Проверка судейских бригад

**Путь:** [Соревнование] → Судьи → Проверка бригад

**Что проверить:**

✅ **D-панель:**
- Минимум 2 судьи (рекомендуется 4)
- Категория Brevet 3 или выше
- Нет конфликта интересов (судьи не из клубов участников)

✅ **E-панель:**
- Минимум 4 судьи (рекомендуется 6)
- Категория Brevet 2 или выше
- Четное количество для исключения крайних значений

✅ **Линейные судьи:**
- 4 судьи (по краям ковра)

**Если есть проблемы:**
- Обратитесь к организатору для замены судей
- Временно назначьте судей из резервного списка

---

#### 4. Контроль процесса оценивания

**Путь:** [Соревнование] → Панель судейства → Живой мониторинг

**Экран показывает:**

**Текущее выступление:**
```
Спортсмен: Анна Иванова (№45)
Клуб: СДЮШОР Динамо
Предмет: Скакалка
Статус: Выступает ⏱️ 1:23 / 1:30
```

**Статус оценок:**
```
D-панель: 3/4 оценок получено ⏳
E-панель: 6/6 оценок получено ✅
Линейные: 0 нарушений ✅
```

**Действия:**
- Если судья не отправил оценку вовремя → отправьте напоминание
- Если оценка сильно отличается от других → проверьте на ошибку

---

#### 5. Разрешение спорных оценок

**Сценарий:** Оценки D-панели сильно различаются

**Пример:**
```
Судья 1: 8.1
Судья 2: 8.2
Судья 3: 7.2 ⚠️ (сильно отличается)
Судья 4: 8.0
```

**Действия:**

1. Система автоматически отметит расхождение: ⚠️ **Внимание: большая разница в оценках D-панели**

2. Нажмите **"Проверить оценку"**

3. **Варианты:**
   - **Принять оценку** (если судья прав)
   - **Запросить пересмотр** (судья пересматривает видео)
   - **Отклонить оценку** (если очевидная ошибка)

4. Добавьте комментарий: "Проверьте количество элементов DA"

5. Судья получит уведомление и сможет:
   - Подтвердить свою оценку с объяснением
   - Исправить оценку

6. После пересмотра подтвердите финальную оценку

---

#### 6. Подтверждение итоговых оценок

**Путь:** [Соревнование] → Оценки → Ожидают подтверждения

**Шаги:**

1. Просмотрите список выступлений с рассчитанными оценками:

```
№45 Анна Иванова | D: 8.05 | E: 9.65 | Final: 17.65 ✅
№46 Мария Петрова | D: 7.80 | E: 9.50 | Final: 17.30 ⏳
```

2. Проверьте каждую оценку:
   - ✅ D-score в допустимом диапазоне
   - ✅ E-score правильно рассчитано (с исключением min/max)
   - ✅ Нейтральные сбавки применены корректно

3. Нажмите **"Подтвердить оценку"** для каждого выступления

4. Или используйте **"Подтвердить все"** для массового подтверждения

**Результат:** Оценки зафиксированы и публикуются в таблице результатов

---

#### 7. Работа с видеообзором (если включен)

**Путь:** [Оценка] → Видео выступления

**Функции:**
- Просмотр записи выступления
- Покадровый просмотр сложных элементов
- Замедленное воспроизведение
- Добавление временных меток и комментариев

**Использование:**
- Для разрешения споров по оценке
- Для обучения судей
- Для апелляций спортсменов

---

### Частые вопросы главного судьи

**Q: Что делать, если судья выставил оценку ошибочно?**
A: Разблокируйте оценку через Панель судейства → найдите выступление → Действия → Разблокировать оценку. Судья сможет исправить.

**Q: Можно ли изменить оценку после публикации результатов?**
A: Да, но это записывается в аудит-лог. Необходимо добавить обоснование изменения.

**Q: Как разрешить ничью?**
A: Система автоматически применяет правила тайбрейка (сравнение E-score → D-score → A-score). Если все равны, присваивается ex aequo (разделенное место).

### Выставление оценок

#### Для D-панели (Сложность)

**Интерфейс:**

```
┌─────────────────────────────────────┐
│ Спортсмен: Анна Иванова (№45)      │
│ Клуб: СДЮШОР Динамо                │
│ Предмет: Скакалка                   │
│ Таймер: ⏱️ 1:15 / 1:30             │
└─────────────────────────────────────┘

D-score компоненты:

DB (Body Difficulties):     [    3.5    ]
DA (Apparatus Difficulties): [    2.4    ]
DS (Dance Steps):           [    0.4    ]
DD (Dynamic Elements):      [    1.8    ]

                    ─────────────────────
Итого D-score:              8.1

Примечания: [                          ]

         [Отправить оценку]
```

**Шаги:**

1. **Наблюдайте за выступлением** и фиксируйте элементы на бумаге

2. **После завершения выступления:**
   - Подсчитайте элементы каждой категории
   - Введите значения в соответствующие поля

3. **DB (Body Difficulties):**
   - Считаются топ-18 элементов (по 0.1-0.7 каждый)
   - Пример: 18 элементов × 0.2 в среднем = 3.6

4. **DA (Apparatus Difficulties):**
   - Топ-6 элементов с предметом (по 0.2-0.6 каждый)
   - Пример: 6 элементов × 0.4 = 2.4

5. **DS (Dance Steps):**
   - 2 танцевальные серии (по 0.1-0.2)
   - Пример: 2 × 0.2 = 0.4

6. **DD (Dynamic Elements):**
   - Динамические элементы (по 0.2-1.0)
   - Пример: 2 элемента (0.8 + 1.0) = 1.8

7. **Проверьте сумму:** DB + DA + DS + DD = 8.1

8. Добавьте примечания (опционально): "Отличная техника вращений"

9. Нажмите **"Отправить оценку"**

**Результат:** Оценка отправлена в систему ✅

---

#### Для E-панели (Исполнение)

**Интерфейс:**

```
┌─────────────────────────────────────┐
│ Спортсмен: Анна Иванова (№45)      │
│ Клуб: СДЮШОР Динамо                │
│ Предмет: Скакалка                   │
└─────────────────────────────────────┘

Начальный балл: 10.0

Сбавки за технику:

Малые ошибки (0.1):    [  1  ] ×0.1 = 0.1
Средние ошибки (0.2):  [  1  ] ×0.2 = 0.2
Крупные ошибки (0.3):  [  0  ] ×0.3 = 0.0
Падение (0.5):         [  0  ] ×0.5 = 0.0

                    ─────────────────────
Общие сбавки:                     0.3

E-score: 10.0 - 0.3 = 9.7

Примечания: [Небольшая потеря равновесия]

         [Отправить оценку]
```

**Типы сбавок:**

| Ошибка | Сбавка | Примеры |
|--------|--------|---------|
| Малая | 0.1 | Незначительное отклонение, небольшая неточность |
| Средняя | 0.2 | Заметная ошибка, потеря равновесия с шагом |
| Крупная | 0.3 | Серьезная ошибка, касание предмета телом |
| Падение | 0.5 | Падение на ковер, потеря предмета за границей |

**Шаги:**

1. Наблюдайте за выступлением
2. Фиксируйте каждую ошибку в соответствующей категории
3. После выступления введите количество ошибок каждого типа
4. Система автоматически рассчитает E-score
5. Проверьте результат
6. Нажмите **"Отправить оценку"**

---

### Работа в офлайн-режиме

**Если потеряна связь:**

1. Система переключится в офлайн-режим: 📴 **Офлайн**
2. Продолжайте выставлять оценки как обычно
3. Оценки сохраняются локально на устройстве
4. При восстановлении связи появится: 🔄 **Синхронизация...**
5. Все оценки автоматически отправятся на сервер
6. Появится подтверждение: ✅ **Синхронизировано**

**Важно:** Не закрывайте браузер до завершения синхронизации!

### Частые вопросы судьи

**Q: Что делать, если я ошибся в оценке?**

**Q: Не успеваю выставить оценку - что делать?**
A: У вас есть до 2 минут после окончания выступления. Если не успеваете, немедленно свяжитесь с главным судьей.

**Q: Можно ли посмотреть оценки других судей?**
A: Нет, до подтверждения оценки других судей скрыты. После подтверждения вы можете увидеть среднее значение.

### Управление ходом выступлений

#### 1. Переключение статусов спортсменов

**Последовательность статусов:**
```
Ожидает → На разминке → Готов → Выступает → Оценивается → Завершено
```

**Действия:**

1. Когда спортсмен выходит на разминку:
   - Нажмите на спортсмена
   - Выберите **"На разминке"**
   - Запустится таймер разминки (обычно 30 сек)

2. Когда спортсмен готов:
   - Нажмите **"Готов к выступлению"**

3. Когда спортсмен начинает выступление:
   - Нажмите **"Начать выступление"**
   - Запустится таймер выступления (90 сек для индивидуальных)

4. Когда выступление закончено:
   - Нажмите **"Завершить выступление"**
   - Статус изменится на "Оценивается"
   - Судьи получат уведомление о необходимости отправки оценок

---

#### 2. Прием оценок от судей

**Индикация получения оценок:**

```
D-панель (Сложность):
  [●] Судья 1: 8.1  ✅
  [●] Судья 2: 8.2  ✅
  [●] Судья 3: 7.9  ✅
  [⚪] Судья 4: ---  ⏳ Ожидание...

E-панель (Исполнение):
  [●] Все 6 судей отправили оценки ✅
```

**Если судья не отправляет оценку:**

1. Подождите 30 секунд
2. Отправьте напоминание: нажмите **"Напомнить судье"**
3. Если судья не отвечает - свяжитесь напрямую
4. В крайнем случае - обратитесь к главному судье

---

#### 3. Расчет итоговой оценки

**Автоматический расчет:**

Система автоматически рассчитывает итоговую оценку при получении всех оценок от судей.

**Формула:**
```
Final Score = D-score + E-score + A-score - ND - Penalties

Где:
- D-score = среднее арифметическое D-панели
- E-score = среднее без min и max значений E-панели
- A-score = среднее A-панели (только для групповых)
- ND = нейтральные сбавки (время, костюм, поведение)
- Penalties = штрафы
```

**Пример расчета:**

```
D-панель:
Судья 1: 8.1
Судья 2: 8.2
Судья 3: 7.9
Судья 4: 8.0
─────────────
Среднее: 8.05

E-панель:
Судья 1: 9.7
Судья 2: 9.6
Судья 3: 9.8  ← max (исключается)
Судья 4: 9.5  ← min (исключается)
Судья 5: 9.7
Судья 6: 9.6
─────────────
Среднее (без min/max): 9.65

Нейтральные сбавки:
Превышение времени на 2 сек: -0.05
─────────────
Итого ND: 0.05

Final Score = 8.05 + 9.65 + 0 - 0.05 - 0 = 17.65
```

**Действия секретаря:**

1. Проверьте правильность расчета (система показывает формулу)
2. Добавьте нейтральные сбавки (если есть):
   - Нажмите **"Добавить сбавку"**
   - Выберите тип: Время / Костюм / Поведение / Другое
   - Укажите величину сбавки
3. Нажмите **"Рассчитать итоговую оценку"**
4. Проверьте результат
5. Отправьте на подтверждение главному судье

---

#### 4. Обработка нарушений и сбавок

**Типы нейтральных сбавок:**

| Нарушение | Сбавка | Кто фиксирует |
|-----------|--------|---------------|
| Превышение времени (1-5 сек) | 0.05 | Таймер / Секретарь |
| Превышение времени (6-10 сек) | 0.10 | Таймер / Секретарь |
| Превышение времени (>10 сек) | 0.20 | Таймер / Секретарь |
| Несоответствие костюма | 0.30 | Главный судья |
| Неспортивное поведение | 0.50-1.00 | Главный судья |
| Выход за границу ковра | 0.30 | Линейный судья |

**Добавление сбавки:**

1. Во время или после выступления нажмите **"Добавить сбавку"**
2. Выберите тип нарушения
3. Система автоматически применит соответствующую сбавку
4. Добавьте комментарий (например, "Вышла за границу на 23 секунде")
5. Нажмите **"Применить"**

**Результат:** Сбавка автоматически вычтется из итоговой оценки

### В день соревнований

#### 1. Прибытие на соревнование

**Что нужно сделать:**

1. **Регистрация:**
   - Подойдите к стойке регистрации
   - Предъявите документ
   - Получите бейдж с вашим номером

2. **Разминка:**
   - Найдите зону разминки
   - Разогрейтесь за 30-40 минут до выступления

3. **Проверка предметов:**
   - Убедитесь, что предметы соответствуют правилам
   - Если есть сомнения - покажите судье по предметам

---

#### 2. Подготовка к выступлению

**За 15 минут:**
- Проверьте костюм и прическу
- Подготовьте предмет
- Пройдите в зону ожидания

**За 5 минут:**
- Следите за экраном - там показывается порядок выступлений
- Когда увидите свой номер как "Следующая" - подойдите к ковру

**Перед выходом:**
- Ассистент вызовет ваш номер: "На ковер приглашается №45, Анна Иванова"
- Выходите на разминку (30 секунд)

---

#### 3. Выступление

1. **Разминка на ковре (30 сек):**
   - Сделайте несколько элементов
   - Привыкните к освещению и покрытию
   - По сигналу судьи займите исходную позицию

2. **Выступление:**
   - Дождитесь сигнала судьи (поднятая рука)
   - Начните под музыку
   - Старайтесь не выходить за границы ковра
   - Выполняйте программу спокойно и уверенно

3. **Завершение:**
   - После финальной позы дождитесь сигнала судьи
   - Поклонитесь
   - Спокойно покиньте ковер

**Важно:**
- Максимальное время: 1:30 для индивидуальных, 2:30 для групповых
- Выход за время: сбавка 0.05-0.20
- Выход за границу: сбавка 0.30

**Если вы не согласны с оценкой:**

A: Нет, кроме форс-мажорных обстоятельств (технические проблемы с музыкой, освещением). Решение принимает главный судья.

### Понимание результатов

#### Как читать оценки

**Пример оценки:**
```
Анна Иванова (№45)

D-score: 8.05  ← Сложность программы
E-score: 9.65  ← Качество исполнения
ND: -0.05      ← Сбавки (время, костюм и т.д.)
─────────────
Final: 17.65   ← Итоговая оценка

Место: 2 из 18
```

**Что означает каждая оценка:**

- **D-score (Difficulty):**Сложность элементов программы. Чем больше сложных элементов, тем выше D-score. Максимум обычно 8-10 баллов.

- **E-score (Execution):**
  Качество исполнения. Начинается с 10.0, вычитаются сбавки за ошибки. Идеальное выступление = 10.0.

- **A-score (Artistry) - только для групповых:**
  Артистизм и синхронность. Оценка 0-10.

- **ND (Neutral Deductions):**
  Нейтральные сбавки: превышение времени, несоответствие костюма, выход за границу.

### Часто задаваемые вопросы зрителя

**Q: Почему результаты не обновляются?**
A: Возможно, проблема с интернетом. Обновите страницу (F5). Если не помогает - спросите у организаторов.

**Q: Можно ли скачать протоколы?**
A: Да, после завершения группы появится кнопка "Скачать протокол" в формате PDF.

**Q: Почему моего ребенка еще нет в списке?**
A: Результаты публикуются после подтверждения главным судьей. Обычно это занимает 2-3 минуты после выступления.

**Q: Как понять, кто победил при одинаковых оценках?**
A: При равенстве итоговых оценок применяется тайбрейк: сравниваются E-score, затем D-score. Если полностью равны - присваивается разделенное место (ex aequo).

### Устранение проблем

#### Типичные проблемы

**1. Система медленно работает**

Решение:
- Проверьте нагрузку (CPU, Memory)
- Очистите логи старше 90 дней
- Проверьте медленные SQL запросы
- Увеличьте размер кеша Redis

**2. Судьи не могут войти**

Решение:
- Проверьте статус учетной записи (не заблокирована ли)
- Сбросьте пароль
- Проверьте логи аутентификации

**3. Оценки не сохраняются**

Решение:
- Проверьте соединение с БД
- Проверьте логи ошибок
- Проверьте место на диске
