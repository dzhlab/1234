# Глоссарий терминов
## Система управления соревнованиями по художественной гимнастике

> **Версия:** 1.0
> **Дата:** 2025-11-26
> **Правила:** FIG 2025-2028

---

## A

### A-Panel (Артистическая бригада)
**Описание:** Судейская бригада, оценивающая артистические компоненты выступления (хореография, музыкальность, выразительность).

**Состав:** 4 судьи

**Выставляет:** A-score (артистическая оценка)

**Диапазон оценки:** 0.00 - 10.00

---

### A-Score (Артистическая оценка)
**Описание:** Балл за артистические компоненты выступления.

**Формула:**
```
A-score = Среднее арифметическое оценок 4 судей A-панели
```

**Пример:**
```
Судья A1: 8.5
Судья A2: 8.7
Судья A3: 8.6
Судья A4: 8.4
A-score = (8.5 + 8.7 + 8.6 + 8.4) / 4 = 8.55
```

---

### Apparatus (Предмет)
**Описание:** Гимнастический предмет, используемый в выступлении.

**Типы предметов:**
- 🎀 **Скакалка** (Rope)
- ⭕ **Обруч** (Hoop)
- ⚽ **Мяч** (Ball)
- 🎯 **Булавы** (Clubs)
- 🎗️ **Лента** (Ribbon)

**Без предмета:** Для определённых категорий (младшие группы)

---

### Athlete (Спортсмен/Гимнастка)
**Описание:** Участник соревнования по художественной гимнастике.

**Категории:**
- Индивидуалки (Individual)
- Групповые гимнастки (Group members)

**Обязательные данные:**
- ФИО
- Дата рождения
- Клуб/регион
- Стартовый номер

---

## C

### Competition (Соревнование)
**Описание:** Спортивное мероприятие, в рамках которого проводятся выступления гимнасток.

**Уровни:**
- Местные
- Региональные
- Национальные
- Международные

**Форматы:**
- Индивидуальное многоборье (All-around)
- Финалы по предметам (Apparatus finals)
- Групповые упражнения (Group)

---

### Chief Judge (Главный судья)
**Описание:** Руководитель судейской коллегии соревнования.

**Обязанности:**
- Контроль за судейством
- Утверждение итоговых оценок
- Разрешение спорных ситуаций
- Проверка соответствия правилам FIG

---

### Chief Secretary (Главный секретарь)
**Описание:** Ответственный за ведение протоколов и обработку результатов.

**Обязанности:**
- Приём оценок от судей
- Расчёт итоговых баллов
- Формирование протоколов
- Публикация результатов

## D

### D-Panel (Бригада сложности)
**Описание:** Судейская бригада, оценивающая техническую сложность элементов выступления.

**Состав:** 4 судьи

**Выставляет:** D-score (оценка сложности)

**Критерии оценки:**
- Сложность элементов тела (Body Difficulty)
- Сложность работы с предметом (Apparatus Difficulty)
- Танцевальные шаги (Dance Steps)
- Динамические элементы с вращением (Dynamic Elements with Rotation)

---

### D-Score (Оценка сложности)
**Описание:** Балл за техническую сложность выступления.

**Формула (FIG 2025-2028):**
```
D-score = DB + DA + DS + DD
```

Где:
- **DB** (Body Difficulty) — сложность элементов тела (максимум 18 элементов по 0.1-0.7)
- **DA** (Apparatus Difficulty) — работа с предметом (максимум 6 элементов по 0.2-0.6)
- **DS** (Dance Steps) — танцевальные комбинации (2 серии по 0.1-0.2)
- **DD** (Dynamic Elements with Rotation) — динамические элементы (2 элемента по 0.2-1.0)

**Максимальный D-score:** ~20.0 баллов (теоретически неограничен)

**Пример:**
```
DB = 5.4 (18 элементов)
DA = 2.4 (6 элементов)
DS = 0.4 (2 серии)
DD = 1.2 (2 элемента)
D-score = 5.4 + 2.4 + 0.4 + 1.2 = 9.4
```

---

### Deduction (Сбавка)
**Описание:** Снижение оценки за ошибки или нарушения.

**Типы сбавок:**

#### 1. Execution Deductions (E-Panel)
- Мелкая ошибка: -0.10
- Средняя ошибка: -0.30
- Серьёзная ошибка: -0.50

#### 2. Neutral Deductions (ND)
- Выход за ковёр: -0.30 (первый), -0.50 (повторный)
- Потеря предмета: -0.70
- Падение гимнастки: -1.00
- Превышение времени: -0.05 за каждую секунду
- Недостаток времени: -0.05 за каждую секунду

#### 3. Penalty (Штраф)
- Запрещённый элемент: -0.50
- Неразрешённая помощь: -0.30
- Нарушение костюма: -0.30

---

## E

### E-Panel (Бригада исполнения)
**Описание:** Судейская бригада, оценивающая качество исполнения элементов.

**Состав:** 4-6 судей

**Выставляет:** E-score (оценка исполнения)

**Критерии оценки:**
- Техника выполнения элементов
- Точность движений
- Работа с предметом (отсутствие потерь)

---

### E-Score (Оценка исполнения)
**Описание:** Балл за качество исполнения, рассчитанный методом исключения крайних значений.

**Формула:**
```
E-score = 10.0 - (среднее арифметическое сбавок средних судей)
```

**Метод расчёта:**
1. Каждый судья E-панели выставляет сбавки
2. Исключаются максимальная и минимальная сбавки
3. Берётся среднее арифметическое оставшихся сбавок
4. Результат вычитается из 10.0

**Пример (6 судей):**
```
Сбавки судей: 1.2, 1.4, 1.5, 1.6, 1.8, 2.0
Исключаем: 1.2 (мин) и 2.0 (макс)
Остаётся: 1.4, 1.5, 1.6, 1.8
Среднее: (1.4 + 1.5 + 1.6 + 1.8) / 4 = 1.575
E-score = 10.0 - 1.575 = 8.425
```

### Event (Событие)
**Описание:** Запланированное мероприятие в рамках соревнования.

**Типы событий:**
- 🎉 **Открытие соревнования** (Opening ceremony)
- 🏋️ **Опробование площадки** (Podium training)
- 🏆 **Награждение** (Award ceremony)
- ☕ **Перерывы** (Break)

**Параметры:**
- Время начала
- Продолжительность
- Ответственное лицо

## F

### FIG (Fédération Internationale de Gymnastique)
**Полное название:** Международная федерация гимнастики

**Описание:** Международная организация, управляющая всеми видами гимнастики.

**Основана:** 1881 год

**Штаб-квартира:** Лозанна, Швейцария

**Функции:**
- Утверждение правил судейства
- Проведение чемпионатов мира и Олимпийских игр
- Сертификация судей
- Регистрация международных результатов

**Официальный сайт:** https://www.gymnastics.sport

---

### Final Score (Итоговая оценка)
**Описание:** Финальный балл за выступление.

**Формула (FIG 2025-2028):**
```
Final Score = D-score + E-score + A-score - ND - Penalties
```

**Пример полного расчёта:**
```
D-score = 9.4
E-score = 8.425
A-score = 8.55
Neutral Deductions (ND) = -0.30 (выход за ковёр)
Penalties = 0.00
Final Score = 9.4 + 8.425 + 8.55 - 0.30 = 26.075
```

## G

### Group (Группа)
**Описание:** Категория участников соревнования, сгруппированных по возрасту, уровню или типу выступления.

**Примеры групп:**
- Индивидуальное многоборье (юниорки)
- Финал: Скакалка (сениорки)
- Групповые упражнения (5 обручей)

---

### Group Exercise (Групповое упражнение)
**Описание:** Выступление команды из 5 гимнасток.

**Типы:**
- **5 одинаковых предметов** (например, 5 мячей)
- **Смешанное** (например, 3 обруча + 2 пары булав)

**Время выступления:** 2'15" - 2'30" (135-150 секунд)

---

## I

### Individual All-Around (Индивидуальное многоборье)
**Описание:** Соревнование, в котором гимнастка выступает с 4 разными предметами.

**Предметы (обычно):**
- Скакалка
- Обруч
- Мяч
- Булавы (или Лента)

**Итоговый балл:** Сумма баллов за все 4 выступления

---

## J

### Judge (Судья)
**Описание:** Лицо, оценивающее выступления гимнасток в соответствии с правилами FIG.

**Типы судей:**
- **D-судья** (оценка сложности)
- **E-судья** (оценка исполнения)
- **A-судья** (артистическая оценка)
- **Line judges** (контроль выхода за ковёр)

**Категории судей FIG:**
- Brevet 5 (высшая категория)
- Brevet 4
- Brevet 3
- Brevet 2
- Brevet 1

---

### Judge Panel (Судейская бригада)
**Описание:** Группа судей, оценивающих выступления.

**Типы бригад:**
- **D-Panel** (4 судьи) — сложность
- **E-Panel** (4-6 судей) — исполнение
- **A-Panel** (4 судьи) — артистизм

**Требования:**
- Минимум 2 судьи с категорией Brevet 3+
- Независимость от страны участниц

---

## N

### Neutral Deduction (ND) (Нейтральная сбавка)
**Описание:** Сбавки за объективные нарушения, не зависящие от судейства.

**Применяются:**
- Координатором сбавок (Deduction Coordinator)
- Автоматически фиксируются

**Примеры:**
- Выход гимнастки за ковёр: -0.30/-0.50
- Потеря предмета за ковром: -0.70
- Падение: -1.00
- Нарушение времени: -0.05/сек

---

## P

### Penalty (Штраф)
**Описание:** Дополнительные сбавки за нарушение правил.

**Применяются:** Главным судьёй или супервизором

**Примеры:**
- Запрещённый элемент: -0.50
- Нарушение костюма: -0.30
- Недопустимая музыка: -0.50
- Неспортивное поведение: -0.30 до дисквалификации

---

### Podium Training (Опробование площадки)
**Описание:** Официальная тренировка на соревновательном ковре перед выступлением.

**Время:** Обычно 30-60 минут

**Цель:**
- Адаптация к освещению
- Проверка музыки
- Ориентация в пространстве

---

## R

### Routine (Упражнение/Выступление)
**Описание:** Полное выступление гимнастки или группы.

**Компоненты:**
- Начальная поза
- Основная часть (элементы + работа с предметом)
- Финальная поза

**Длительность:**
- Индивидуальное: 1'15" - 1'30"
- Групповое: 2'15" - 2'30"

---

## S

### Senior (Сениорка)
**Описание:** Старшая возрастная категория гимнасток.

**Возраст:** 16+ лет (год рождения: 2009 и старше для 2025 года)

**Особенности:**
- Полный регламент FIG
- Максимальная сложность элементов
- Участие в Олимпийских играх

---

### Start List (Стартовый протокол)
**Описание:** Документ с порядком выступлений спортсменок.

**Содержит:**
- Стартовый номер
- ФИО гимнастки
- Страна/регион
- Время выхода
- Предмет (для финалов)

**Формирование:**
- Жеребьёвка (для квалификации)
- По результатам (для финалов: от худшего к лучшему)

---

### Score (Оценка/Балл)
**Описание:** Числовое значение, выставленное судьями за выступление.

**Типы:**
- D-score (сложность)
- E-score (исполнение)
- A-score (артистизм)
- Final Score (итоговая оценка)

## T

### Technical Specialist (Технический специалист)
**Описание:** Ответственный за техническое обеспечение соревнования.

**Обязанности:**
- Настройка оборудования
- Работа с музыкой
- Управление табло
- Решение технических проблем

---

### Tiebreak (Разрешение ничьей)
**Описание:** Правило определения места при одинаковых итоговых баллах.

**Алгоритм FIG 2025-2028:**
1. Сравнить E-score (у кого выше — тот выше)
2. Если E-score равны → сравнить D-score
3. Если D-score равны → сравнить A-score
4. Если все равны → присвоить одинаковое место (ex aequo)

**Пример:**
```
Гимнастка A: Final = 26.500 (D=9.2, E=8.7, A=8.6)
Гимнастка B: Final = 26.500 (D=9.4, E=8.5, A=8.6)

Итоговые баллы равны → сравниваем E-score
E-score A (8.7) > E-score B (8.5)
Результат: Гимнастка A занимает более высокое место
```

## W

### Warm-up (Разминка)
**Описание:** Подготовка перед выступлением.

**Типы:**
- **Общая разминка** (Off-podium warm-up) — в зале разминки
- **Разминка на ковре** (On-podium warm-up) — 30 секунд перед выступлением

**Правила:**
- Без музыки
- Только с предметом выступления
- Строго ограничено по времени
