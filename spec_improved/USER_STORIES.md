## Организатор соревнований

### US-ORG-001: Создание соревнования 🔴
**Как** организатор,
**Я хочу** создать новое соревнование с указанием названия, дат и места проведения,
**Чтобы** начать подготовку к мероприятию.

**Acceptance Criteria:**
- [ ] Форма содержит обязательные поля: название, город, место, даты
- [ ] Валидация: дата окончания >= дата начала
- [ ] Автоматическая генерация структуры дней и событий
- [ ] Присвоение уникального ID соревнованию

---

### US-ORG-002: Копирование структуры соревнования 🟡
**Как** организатор,
**Я хочу** скопировать структуру из прошлого соревнования,
**Чтобы** не вводить все данные заново.

**Acceptance Criteria:**
- [ ] Выбор соревнования из списка
- [ ] Копируются: группы, события, настройки регламента
- [ ] НЕ копируются: спортсмены, результаты, даты

---

### US-ORG-003: Регистрация спортсменов 🔴
**Как** организатор,
**Я хочу** зарегистрировать спортсменов на соревнование,
**Чтобы** они могли участвовать в выступлениях.

**Acceptance Criteria:**
- [ ] Поиск спортсменов по ФИО
- [ ] Автоматическое присвоение стартового номера
- [ ] Проверка на дубликаты стартовых номеров
- [ ] Возможность массовой регистрации (импорт из Excel)

---

### US-ORG-004: Настройка групп и категорий 🔴
**Как** организатор,
**Я хочу** создать группы (индивидуальное многоборье, финалы по предметам),
**Чтобы** структурировать соревнование.

**Acceptance Criteria:**
- [ ] Создание группы с указанием категории и предмета
- [ ] Привязка к дате соревнования
- [ ] Указание максимального количества участников

---

### US-ORG-005: Формирование судейских бригад 🔴
**Как** организатор,
**Я хочу** назначить судей на бригады (D, E, A),
**Чтобы** обеспечить судейство выступлений.

**Acceptance Criteria:**
- [ ] Выбор судей из списка
- [ ] Минимум 4 судьи на бригаду
- [ ] Проверка конфликтов (один судья не может быть в двух бригадах одновременно)

---

### US-ORG-006: Удаление соревнования 🔴
**Как** организатор,
**Я хочу** удалить соревнование с подтверждением,
**Чтобы** избежать случайного удаления.

**Acceptance Criteria:**
- [ ] Показ предупреждения о каскадном удалении
- [ ] Требование ввести название соревнования для подтверждения
- [ ] Логирование действия удаления

---

### US-ORG-007: Экспорт данных соревнования 🟡
**Как** организатор,
**Я хочу** экспортировать протоколы и результаты в PDF/Excel,
**Чтобы** отправить их в федерацию или опубликовать.

**Acceptance Criteria:**
- [ ] Форматы: PDF, Excel, CSV
- [ ] Включение логотипов и брендинга
- [ ] Выбор данных для экспорта (все группы или выборочно)

---

### US-ORG-008: Просмотр статистики соревнования 🟢
**Как** организатор,
**Я хочу** видеть общую статистику (количество спортсменов, завершённых выступлений),
**Чтобы** контролировать ход соревнования.

**Acceptance Criteria:**
- [ ] Дашборд с метриками
- [ ] Обновление в реальном времени
- [ ] Графики прогресса

## Главный судья

### US-CJ-001: Контроль оценок 🔴
**Как** главный судья,
**Я хочу** видеть все оценки бригад в реальном времени,
**Чтобы** контролировать процесс судейства.

**Acceptance Criteria:**
- [ ] Панель с текущими выступлениями
- [ ] Отображение оценок D, E, A для каждого судьи
- [ ] Выделение выбросов (слишком высокие/низкие оценки)

---

### US-CJ-002: Утверждение итоговых оценок 🔴
**Как** главный судья,
**Я хочу** утверждать итоговые оценки после проверки,
**Чтобы** результаты стали официальными.

**Acceptance Criteria:**
- [ ] Кнопка "Утвердить" для каждого выступления
- [ ] Возможность вернуть оценку на доработку
- [ ] История утверждений (кто, когда)

---

### US-CJ-003: Разрешение спорных ситуаций 🟡
**Как** главный судья,
**Я хочу** вручную скорректировать оценку в случае ошибки,
**Чтобы** обеспечить справедливость.

**Acceptance Criteria:**
- [ ] Доступ к редактированию подтверждённых оценок
- [ ] Обязательное указание причины изменения
- [ ] Логирование всех корректировок

---

### US-CJ-004: Просмотр видео выступления 🟢
**Как** главный судья,
**Я хочу** просмотреть видеозапись выступления при спорной ситуации,
**Чтобы** принять обоснованное решение.

**Acceptance Criteria:**
- [ ] Интеграция с видеосистемой
- [ ] Доступ к видео по ID выступления
- [ ] Возможность замедленного воспроизведения

## Судья

### US-J-001: Быстрое выставление оценки 🔴
**Как** судья,
**Я хочу** выставить оценку за выступление за минимальное количество кликов,
**Чтобы** не задерживать процесс.

**Acceptance Criteria:**
- [ ] Интерфейс с крупными кнопками (для планшетов)
- [ ] Автосохранение при вводе
- [ ] Подтверждение отправки оценки

---

### US-J-002: Фиксация сбавок (E-Panel) 🔴
**Как** судья E-панели,
**Я хочу** фиксировать сбавки за ошибки во время выступления,
**Чтобы** точно оценить исполнение.

**Acceptance Criteria:**
- [ ] Категории сбавок: мелкая (0.1), средняя (0.3), серьёзная (0.5)
- [ ] Добавление комментариев к сбавкам
- [ ] Автоматический расчёт итоговой оценки (10.0 - сбавки)

---

### US-J-003: Оценка сложности (D-Panel) 🔴
**Как** судья D-панели,
**Я хочу** подсчитать оценку сложности (D-score) по компонентам (DB, DA, DS, DD),
**Чтобы** выставить корректную оценку.

**Acceptance Criteria:**
- [ ] Отдельные поля для DB, DA, DS, DD
- [ ] Автоматическая сумма компонентов
- [ ] Проверка на максимальные значения (DB max 18 элементов)

---

### US-J-004: Просмотр истории оценок 🟡
**Как** судья,
**Я хочу** видеть свои ранее выставленные оценки,
**Чтобы** поддерживать консистентность судейства.

**Acceptance Criteria:**
- [ ] История последних 10 оценок
- [ ] Фильтр по дате и группе
- [ ] Средняя оценка за день

---

### US-J-005: Оффлайн-режим 🟡
**Как** судья,
**Я хочу** продолжать выставлять оценки при потере сети,
**Чтобы** не прерывать процесс.

**Acceptance Criteria:**
- [ ] Локальное сохранение оценок
- [ ] Автоматическая синхронизация при восстановлении сети
- [ ] Индикатор статуса подключения

---

## Секретарь

### US-SEC-001: Приём оценок от судей 🔴
**Как** секретарь,
**Я хочу** видеть статус получения оценок от всех судей,
**Чтобы** знать, когда можно рассчитывать итоговый балл.

**Acceptance Criteria:**
- [ ] Панель с индикаторами (зелёный = получено, красный = ожидание)
- [ ] Уведомление при получении всех оценок
- [ ] Возможность запросить оценку у конкретного судьи

---

### US-SEC-002: Расчёт итоговой оценки 🔴
**Как** секретарь,
**Я хочу** запустить расчёт итоговой оценки после получения всех данных,
**Чтобы** опубликовать результат.

**Acceptance Criteria:**
- [ ] Кнопка "Рассчитать итоговую оценку"
- [ ] Показ формулы расчёта (D + E + A - ND - Penalties)
- [ ] Автоматическая публикация результата

---

### US-SEC-003: Формирование протоколов 🔴
**Как** секретарь,
**Я хочу** сформировать стартовый и итоговый протоколы,
**Чтобы** распространить их среди участников.

**Acceptance Criteria:**
- [ ] Автоматическая генерация PDF
- [ ] Фирменный бланк с логотипом
- [ ] Сортировка по местам

---

### US-SEC-004: Обработка ничьих 🟡
**Как** секретарь,
**Я хочу** видеть правила разрешения ничьей при одинаковых баллах,
**Чтобы** корректно присвоить места.

**Acceptance Criteria:**
- [ ] Автоматическое применение правила FIG (сравнение E-score, затем D-score)
- [ ] Отображение правила на экране
- [ ] Возможность присвоить ex aequo (равное место)

---

### US-SEC-005: Отправка уведомлений 🟢
**Как** секретарь,
**Я хочу** отправить SMS/Email спортсменкам о времени выступления,
**Чтобы** они не пропустили свой номер.

**Acceptance Criteria:**
- [ ] Массовая рассылка за 30 минут до выступления
- [ ] Шаблоны сообщений
- [ ] Логирование отправленных уведомлений

---

## Спортсмен

### US-ATH-001: Просмотр расписания 🔴
**Как** спортсменка,
**Я хочу** видеть расписание своих выступлений,
**Чтобы** вовремя подготовиться.

**Acceptance Criteria:**
- [ ] Мобильная версия сайта
- [ ] Фильтр "Мои выступления"
- [ ] Уведомления за 30 минут до выступления

---

### US-ATH-002: Просмотр результатов в реальном времени 🔴
**Как** спортсменка,
**Я хочу** видеть свои результаты сразу после выступления,
**Чтобы** знать, на каком месте я нахожусь.

**Acceptance Criteria:**
- [ ] Обновление результатов через WebSocket
- [ ] Отображение места, D-score, E-score, A-score, итоговой оценки
- [ ] Отображение отставания от лидера

---

### US-ATH-003: Просмотр истории выступлений 🟡
**Как** спортсменка,
**Я хочу** видеть свою статистику по прошлым соревнованиям,
**Чтобы** отслеживать прогресс.

**Acceptance Criteria:**
- [ ] Личный кабинет
- [ ] Графики динамики оценок
- [ ] Сравнение с предыдущими соревнованиями

---

## Зритель / Родитель

### US-VIEW-001: Просмотр текущих результатов 🔴
**Как** зритель,
**Я хочу** видеть результаты соревнования в реальном времени,
**Чтобы** следить за ходом событий.

**Acceptance Criteria:**
- [ ] Публичная страница без авторизации
- [ ] Обновление результатов в реальном времени
- [ ] Фильтр по категориям и группам

---

### US-VIEW-002: Поиск спортсменки 🟡
**Как** родитель,
**Я хочу** быстро найти результаты своего ребёнка,
**Чтобы** не искать в большом списке.

**Acceptance Criteria:**
- [ ] Поиск по ФИО
- [ ] Поиск по стартовому номеру
- [ ] Фильтр по клубу/региону

---

### US-VIEW-003: Подписка на уведомления 🟢
**Как** родитель,
**Я хочу** получать уведомления о выступлении моего ребёнка,
**Чтобы** не пропустить важный момент.

**Acceptance Criteria:**
- [ ] Email/SMS уведомления
- [ ] Push-уведомления (PWA)
- [ ] Настройка времени заблаговременности (за 30 мин, за 15 мин)

## Администратор системы

### US-ADM-001: Управление пользователями 🔴
**Как** администратор,
**Я хочу** создавать учётные записи пользователей и назначать роли,
**Чтобы** контролировать доступ к системе.

**Acceptance Criteria:**
- [ ] CRUD операции для пользователей
- [ ] Назначение ролей (Admin, Organizer, Judge, Secretary, Viewer)
- [ ] Блокировка/разблокировка учётной записи

---

### US-ADM-002: Просмотр логов 🟡
**Как** администратор,
**Я хочу** просматривать логи действий пользователей,
**Чтобы** отслеживать подозрительную активность.

**Acceptance Criteria:**
- [ ] Фильтр по дате, пользователю, типу действия
- [ ] Экспорт логов в CSV
- [ ] Поиск по ключевым словам

---

### US-ADM-003: Резервное копирование 🔴
**Как** администратор,
**Я хочу** создавать резервные копии базы данных,
**Чтобы** обеспечить сохранность данных.

**Acceptance Criteria:**
- [ ] Ручное создание бэкапа
- [ ] Автоматические бэкапы по расписанию
- [ ] Восстановление из бэкапа за < 30 минут

---

### US-ADM-004: Мониторинг системы 🟡
**Как** администратор,
**Я хочу** видеть метрики производительности системы,
**Чтобы** предотвращать сбои.

**Acceptance Criteria:**
- [ ] Дашборд с метриками (CPU, RAM, DB connections)
- [ ] Алерты при превышении лимитов
- [ ] История метрик за 30 дней
