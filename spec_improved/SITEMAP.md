## Общая структура навигации

```mermaid
graph TD
    ROOT[Корневая страница /]

    ROOT --> AUTH[Аутентификация]
    ROOT --> PUBLIC[Публичные страницы]
    ROOT --> ADMIN[Административная панель]

    AUTH --> LOGIN[/login - Вход]
    AUTH --> LOGOUT[/logout - Выход]

    PUBLIC --> HOME[/ - Главная]
    PUBLIC --> RESULTS[/results - Результаты]
    PUBLIC --> SCHEDULE[/schedule - Расписание]

    ADMIN --> DASH[/dashboard - Панель управления]
    DASH --> COMP[Соревнования]
    DASH --> ATH[Спортсмены]
    DASH --> JUDGES[Судьи]
    DASH --> USERS[Пользователи]

    COMP --> COMP_LIST[/competitions - Список]
    COMP --> COMP_CREATE[/competitions/create]
    COMP --> COMP_DETAIL[/competitions/:id]

    style ROOT fill:#4A90E2
    style PUBLIC fill:#50C878
    style ADMIN fill:#FFB347
```

## Детальное описание экранов

### 1. Главная страница (/)

**URL:** `/`
**Доступ:** Все (публичный)
**Тип:** Информационный

**Компоненты:**
- Список активных соревнований
- Новости и объявления
- Быстрый поиск спортсменов
- Ссылки на результаты

**Навигация:**
- → `/results` - Просмотр результатов
- → `/schedule` - Расписание
- → `/login` - Вход в систему

---

### 2. Вход в систему (/login)

**URL:** `/login`
**Доступ:** Все (публичный)
**Тип:** Форма

**Поля:**
- Email
- Пароль
- [ ] Запомнить меня

**Кнопки:**
- [Войти] → `/dashboard` (после успешной авторизации)
- Забыли пароль? → `/forgot-password`

**Редиректы:**
- Admin/Organizer → `/dashboard`
- Judge → `/judge/dashboard`
- Secretary → `/secretary/dashboard`
- Viewer → `/` (с авторизованным меню)

---

### 3. Панель управления (/dashboard)

**URL:** `/dashboard`
**Доступ:** Admin, Organizer, Chief Judge, Secretary
**Тип:** Dashboard

**Виджеты:**
- Активные соревнования
- Недавние действия
- Уведомления
- Статистика (количество спортсменов, судей)

**Быстрые действия:**
- [+ Создать соревнование] → `/competitions/create`
- [+ Добавить спортсменку] → `/athletes/create`
- [Просмотреть результаты] → `/results`

---

### 4. Список соревнований (/competitions)

**URL:** `/competitions`
**Доступ:** Admin, Organizer, Chief Judge, Secretary
**Тип:** Список с фильтрами

**Фильтры:**
- Статус: Все / Активные / Завершённые / Архивные
- Дата: С / По
- Поиск по названию

**Таблица:**
| Название | Город | Даты | Статус | Действия |
|----------|-------|------|--------|----------|
| Первенство Москвы | Москва | 15-18 апр | Активное | [Открыть] [Редактировать] [Удалить] |

**Кнопки:**
- [+ Создать соревнование] → `/competitions/create`

---

### 5. Создание соревнования (/competitions/create)

**URL:** `/competitions/create`
**Доступ:** Admin, Organizer
**Тип:** Многошаговая форма (wizard)

**Шаги:**
1. **Основная информация**
   - Название
   - Город
   - Место проведения
   - Дата начала/окончания

2. **Категории**
   - [ ] Младшие (6-10 лет)
   - [ ] Девочки (11-12 лет)
   - [ ] Юниорки (13-15 лет)
   - [ ] Сениорки (16+ лет)

3. **Копирование структуры** (опционально)
   - Выбор соревнования для копирования

**Кнопки:**
- [Назад]
- [Далее]
- [Создать] → `/competitions/:id`

---

### 6. Детали соревнования (/competitions/:id)

**URL:** `/competitions/:id`
**Доступ:** Admin, Organizer, Chief Judge, Secretary
**Тип:** Страница с табами

**Табы:**
- **Обзор** - основная информация
- **Группы** - управление группами
- **Спортсмены** - регистрация участников
- **Судьи** - назначение судейских бригад
- **Расписание** - события и даты
- **Результаты** - просмотр итогов
- **Настройки** - параметры соревнования

**Быстрые действия:**
- [Редактировать]
- [Экспорт протоколов]
- [Удалить соревнование]

---

### 7. Управление группами (/competitions/:id/groups)

**URL:** `/competitions/:id/groups`
**Доступ:** Admin, Organizer, Chief Judge
**Тип:** Список + модальные окна

**Список групп:**
| Название | Категория | Предмет | Участники | Дата | Действия |
|----------|-----------|---------|-----------|------|----------|
| Индивид. многоборье (Сениорки) | Senior | All-Around | 25 | 15 апр | [Открыть] [Редактировать] |

**Кнопки:**
- [+ Добавить группу] → Модальное окно создания

**Модальное окно создания группы:**
- Название
- Категория (dropdown)
- Предмет (dropdown)
- Дата (выбор из дат соревнования)
- Максимум участников

---

### 8. Регистрация спортсменов (/competitions/:id/athletes)

**URL:** `/competitions/:id/athletes`
**Доступ:** Admin, Organizer
**Тип:** Два столбца (доступные / зарегистрированные)

**Левый столбец - Доступные спортсмены:**
- Поиск по ФИО
- Фильтр по клубу/региону
- [+ Добавить нового спортсмена]

**Правый столбец - Зарегистрированные:**
- Список с стартовыми номерами
- Статус регистрации
- [Удалить из соревнования]

**Действия:**
- Перетаскивание (drag & drop)
- Массовая регистрация (импорт Excel)

---

## Навигационные потоки

### Поток 1: Создание и проведение соревнования

```mermaid
flowchart LR
    A[/login] --> B[/dashboard]
    B --> C[/competitions/create]
    C --> D[/competitions/:id]
    D --> E[/competitions/:id/groups]
    E --> F[/competitions/:id/athletes]
    F --> G[/competitions/:id/judges]
    G --> H[/competitions/:id/start-lists]
    H --> I[/judge/scoring]
    I --> J[/secretary/approve-scores]
    J --> K[/display/live]
```

### Поток 2: Судья выставляет оценку

```mermaid
flowchart LR
    A[/login] --> B[/judge/dashboard]
    B --> C[/judge/select-panel]
    C --> D[/judge/scoring/e-panel]
    D --> E[Отправка оценки]
    E --> F[/judge/history]
```

### Поток 3: Просмотр результатов (публичный)

```mermaid
flowchart LR
    A[/] --> B[/results]
    B --> C[/results/:competitionId]
    C --> D[/athlete/:id]
```
