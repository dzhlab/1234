## Введение

### Цель документа

Этот документ содержит полный набор тест-кейсов для тестирования системы управления соревнованиями по художественной гимнастике.

### Обозначения

| Символ | Значение |
|--------|----------|
| ✅ | Passed (тест пройден) |
| ❌ | Failed (тест провален) |
| ⏸️ | Blocked (заблокирован) |
| ⏭️ | Skipped (пропущен) |
| 🔴 | Critical (критический) |
| 🟡 | Major (важный) |
| 🟢 | Minor (незначительный) |

**Приоритет:** Critical

**Предусловия:**
- 4 судьи E-панели выставили сбавки:
  - Судья 1: 0.40 (E-score: 9.60)
  - Судья 2: 0.50 (E-score: 9.50)
  - Судья 3: 0.60 (E-score: 9.40)
  - Судья 4: 0.70 (E-score: 9.30)

**Шаги:**
1. Секретарь нажимает "Рассчитать E-score"

**Ожидаемый результат:**
- Исключены: 0.40 (мин) и 0.70 (макс)
- Остались: 0.50, 0.60
- Среднее: (0.50 + 0.60) / 2 = 0.55
- E-score = 10.0 - 0.55 = 9.450
- HTTP статус: 200 OK

**Статус:** ⬜
