## 1. Управление соревнованиями

### 1.1. Создание нового соревнования

#### Описание
Создание нового соревнования с автоматической генерацией базовой структуры.

#### Интерфейс

**Форма создания соревнования:**

```
┌────────────────────────────────────────────────────────┐
│          СОЗДАНИЕ НОВОГО СОРЕВНОВАНИЯ                  │
├────────────────────────────────────────────────────────┤
│                                                        │
│  Название соревнования: *                              │
│  ┌──────────────────────────────────────────────────┐  │
│  │ [Открытое первенство города Москвы]              │  │
│  └──────────────────────────────────────────────────┘  │
│                                                        │
│  Город: *                                              │
│  ┌──────────────────────────────────────────────────┐  │
│  │ [Москва]                                         │  │
│  └──────────────────────────────────────────────────┘  │
│                                                        │
│  Место проведения: *                                   │
│  ┌──────────────────────────────────────────────────┐  │
│  │ [СК "Олимпийский"]                               │  │
│  └──────────────────────────────────────────────────┘  │
│                                                        │
│  Дата начала: *        Дата окончания: *               │
│  ┌──────────────┐     ┌──────────────┐                 │
│  │ 15.04.2025   │     │ 18.04.2025   │                 │
│  └──────────────┘     └──────────────┘                 │
│                                                        │
│  Вид спорта: *                                         │
│  ┌──────────────────────────────────────────────────┐  │
│  │ [▼] Художественная гимнастика                    │  │
│  └──────────────────────────────────────────────────┘  │
│                                                        │
│  Возрастные категории: *                               │
│  ☑ Младшие (6-10 лет)                                  │
│  ☑ Девочки (11-12 лет)                                 │
│  ☑ Юниорки (13-15 лет)                                 │
│  ☑ Сениорки (16+ лет)                                  │
│                                                        │
│  ┌─────────────────────────────────────┐               │
│  │ 📋 Копировать из существующего      │               │
│  │    соревнования: [▼ Выбрать...]     │               │
│  └─────────────────────────────────────┘               │
│                                                        │
│  [Отмена]                            [Создать] ✓       │
│                                                        │
└────────────────────────────────────────────────────────┘
```

#### Поля формы

| Поле | Тип | Обязательное | Описание |
|------|-----|--------------|----------|
| **Название соревнования** | Текст | ✅ Да | Полное название соревнования |
| **Город** | Текст | ✅ Да | Город проведения |
| **Место проведения** | Текст | ✅ Да | Спортивный комплекс, адрес |
| **Дата начала** | Дата | ✅ Да | Первый день соревнования |
| **Дата окончания** | Дата | ✅ Да | Последний день соревнования |
| **Вид спорта** | Выпадающий список | ✅ Да | Художественная гимнастика (по умолчанию) |
| **Возрастные категории** | Чекбоксы | ✅ Да | Выбор категорий участников |
| **Копировать из** | Выпадающий список | ❌ Нет | Опциональное копирование структуры |

#### Валидация

**Правила проверки:**
```javascript
// Дата окончания >= Дата начала
if (dateEnd < dateStart) {
    ERROR: "Дата окончания не может быть раньше даты начала"
}

// Минимум 1 возрастная категория
if (categories.length === 0) {
    ERROR: "Выберите хотя бы одну возрастную категорию"
}

// Название не пустое и не дублируется
if (name.trim() === "") {
    ERROR: "Введите название соревнования"
}

if (competitionExists(name, dateStart)) {
    WARNING: "Соревнование с таким названием и датой уже существует"
}
```

#### Автоматическая генерация при создании

После нажатия "Создать" система автоматически:

1. **Создает структуру дат:**
   - Генерирует дни соревнования от даты начала до даты окончания
   - Устанавливает время начала дня: `09:00` (по умолчанию)

2. **Создает базовые категории групп:**
   ```
   Для каждой выбранной возрастной категории:
   ├─ Индивидуальное многоборье
   ├─ Финал: Скакалка
   ├─ Финал: Обруч
   ├─ Финал: Мяч
   ├─ Финал: Булавы
   └─ Финал: Лента
   ```

3. **Создает стандартные события:**
   - День 1: "Открытие соревнования" (09:00, 30 мин)
   - День 1: "Опробование площадки" (после открытия, 60 мин)
   - Последний день: "Награждение" (окончание дня - 60 мин)

4. **Присваивает уникальный ID:**
   ```javascript
   competitionId = `COMP_${timestamp}_${randomString(6)}`
   // Пример: COMP_1711267200_A7B9C3
   ```

#### Функция "Копировать из существующего соревнования"

**Что копируется:**
- ✅ Структура групп и категорий
- ✅ События (типы и продолжительность)
- ✅ Настройки регламента (время выступления, перерывы)
- ✅ Состав судейских бригад (шаблон)

**Что НЕ копируется:**
- ❌ Участники (спортсмены)
- ❌ Конкретные даты (создаются новые)
- ❌ Результаты соревнований

#### Пример использования

**Сценарий 1: Создание с нуля**
```
1. Пользователь заполняет форму
2. Выбирает категории: Юниорки, Сениорки
3. Нажимает "Создать"
4. Система создает структуру:
   - 4 дня (15-18 апреля)
   - 12 групп (2 категории × 6 видов)
   - 3 события (открытие, опробование, награждение)
```

**Сценарий 2: Копирование**
```
1. Пользователь выбирает "Копировать из: Первенство Москвы 2024"
2. Система автоматически заполняет:
   - Те же категории
   - Ту же структуру групп
   - Те же события
3. Пользователь меняет только даты и название
4. Нажимает "Создать"
```

### 1.2. Удаление соревнования

#### Описание

```
│    [Редактировать] [🗑️ Удалить]        │
│                                        │
└────────────────────────────────────────┘
```

**Диалог подтверждения:**
```
┌────────────────────────────────────────────────────────┐
│  ⚠️  ПОДТВЕРЖДЕНИЕ УДАЛЕНИЯ                            │
├────────────────────────────────────────────────────────┤

│                                                        │

│  • 156 участников                                      │
│  • 48 групп/потоков                                    │

│  [Отмена]                        [Удалить навсегда]    │
│                                                        │
└────────────────────────────────────────────────────────┘
```

#### Каскадное удаление

**Что удаляется вместе с соревнованием:**

```
СОРЕВНОВАНИЕ
├─ ДАТЫ
│  └─ Все дни соревнования
│
├─ ГРУППЫ/ПОТОКИ
│  ├─ Индивидуальное многоборье
│  ├─ Финалы по предметам
│  └─ Групповые упражнения
│
├─ СОБЫТИЯ
│  ├─ Открытие
│  ├─ Перерывы
│  ├─ Награждения
│  └─ Прочие
│
├─ УЧАСТНИКИ (ПРИВЯЗКИ)
│  ├─ Связь спортсменов с соревнованием
│  └─ Стартовые номера
│  (Сами спортсмены НЕ удаляются из общей базы)
│
├─ СУДЕЙСКИЕ БРИГАДЫ
│  ├─ Бригады D, A, E
│  └─ Назначения судей
│  (Сами судьи НЕ удаляются из общей базы)
│
├─ РЕЗУЛЬТАТЫ
│  ├─ Все оценки судей
│  ├─ Итоговые баллы
│  └─ Протоколы
│
└─ СТАРТОВЫЕ ПРОТОКОЛЫ
   ├─ Очередность выступлений
   └─ Расписание
```

#### Уровни защиты от случайного удаления

**Уровень 1: Предупреждение**
- Отображается количество связанных данных
- Список того, что будет удалено

**Уровень 2: Подтверждение названия**
- Пользователь должен ввести название соревнования
- Защита от случайного клика

**Уровень 3: Роли**
- Удалять могут только:
  - ✅ Организатор
  - ✅ Главный судья
  - ❌ Секретарь (нет доступа)
  - ❌ Судья (нет доступа)

#### SQL-транзакция

```sql
BEGIN TRANSACTION;

-- 1. Удаление результатов
DELETE FROM scores WHERE competition_id = ?;

-- 2. Удаление назначений судей
DELETE FROM judge_assignments WHERE competition_id = ?;

-- 3. Удаление судейских бригад
DELETE FROM judge_panels WHERE competition_id = ?;

-- 4. Удаление привязок спортсменов
DELETE FROM athlete_registrations WHERE competition_id = ?;

-- 5. Удаление стартовых протоколов
DELETE FROM start_lists WHERE competition_id = ?;

-- 6. Удаление событий
DELETE FROM events WHERE competition_id = ?;

-- 7. Удаление групп/потоков
DELETE FROM groups WHERE competition_id = ?;

-- 8. Удаление дат
DELETE FROM competition_dates WHERE competition_id = ?;

-- 9. Удаление самого соревнования
DELETE FROM competitions WHERE id = ?;

COMMIT;
```

#### Логирование

Каждое удаление записывается в журнал:

```json
{
  "action": "DELETE_COMPETITION",
  "timestamp": "2025-03-15T14:32:00Z",
  "user_id": "USER_12345",
  "user_role": "Организатор",
  "competition_id": "COMP_1711267200_A7B9C3",
  "competition_name": "Открытое первенство Москвы",
  "deleted_data": {
    "athletes": 156,
    "groups": 48,
    "judges": 36,
    "scores": 1248
  }
}
```

При изменении параметров регламента система автоматически пересчитывает:

```

    ↓
Пересчет времени окончания каждой группы
    ↓
Сдвиг следующих групп и событий
    ↓
Обновление общего расписания
```

#### Пример использования

**Сценарий: Изменение времени разминки**
```

2. Система пересчитывает:
   - Каждая гимнастка теперь занимает на 15 секунд больше
   - Группа из 20 человек = +5 минут к общему времени
   - Сдвигает начало следующих групп на 5 минут
3. Показывает предупреждение:
   "⚠️ Изменение времени разминки сдвинет расписание.
   Следующие группы начнутся на 5 минут позже."
4. Пользователь подтверждает
5. Система обновляет расписание
```

##### Формула расчета времени группы:

```javascript
function calculateGroupDuration(group) {
  const athletesCount = group.athletes.length;
  const performanceTime = group.type === 'individual' ? 90 : 150; // секунды
  const warmupTime = group.type === 'individual' ? 30 : 60;       // секунды
  const transitionTime = 60;  // секунды между выступлениями

  const timePerAthlete = performanceTime + warmupTime + transitionTime;
  const totalSeconds = athletesCount * timePerAthlete;

  // Добавляем 10% на технические задержки
  const buffer = totalSeconds * 0.1;

  return Math.ceil((totalSeconds + buffer) / 60); // минуты
}
```

##### Пример расчета:

```
Группа: Юниорки • Многоборье
Участников: 20
Тип: Индивидуальное

Время на одного:
  90 сек (выступление) +
  30 сек (разминка) +
  60 сек (переход) =
  180 сек = 3 минуты

Общее время:
  20 × 3 мин = 60 мин
  + 10% буфер = 6 мин
  Итого: 66 минут ≈ 1ч 6мин
```

#### Алгоритм автоматического отбора

```javascript
function selectFinalists(qualificationResults, count = 8) {
  // 1. Сортировка по баллам (убывание)
  const sorted = qualificationResults
    .sort((a, b) => b.totalScore - a.totalScore);

  // 2. Отбор TOP-N
  const finalists = sorted.slice(0, count);

  // 3. Обработка равенства баллов (тай-брейк)
  const lastScore = finalists[count - 1].totalScore;
  const tiedAthletes = sorted.filter(a => a.totalScore === lastScore);

  if (tiedAthletes.length > 1) {
    // Применить правила тай-брейка FIG
    return applyTieBreakRules(finalists, tiedAthletes);
  }

  return finalists;
}
```

#### Правила тай-брейка FIG

Если несколько спортсменов имеют одинаковый балл:

```
1. Сравнить оценку E (Execution)
   Выше E → выше место
   ↓
2. Если E равны, сравнить оценку D (Difficulty)
   Выше D → выше место
   ↓
3. Если D и E равны, сравнить оценку A (Artistry)
   Выше A → выше место
   ↓
4. Если все оценки равны → делят место (ex aequo)
```

### 2.4. Автоматический пересчёт

#### Логика пересчета

**При изменении первой даты:**
```javascript
// Сдвиг всех дат
function shiftDatesFromStart(newFirstDate, oldFirstDate) {
  const diff = daysBetween(newFirstDate, oldFirstDate);

  allDays.forEach((day, index) => {
    if (index > 0) {
      day.date = addDays(day.date, diff);
    }
  });
}
```

**При изменении последней даты:**
```javascript
// Только последний день меняется
function changeLastDate(newLastDate) {
  const lastDayIndex = allDays.length - 1;
  allDays[lastDayIndex].date = newLastDate;
}
```

**При изменении времени начала дня:**
```javascript
// Пересчет времени всех элементов дня
function recalculateDay(day) {
  let currentTime = day.startTime;

  day.items.forEach(item => {
    item.startTime = currentTime;
    item.endTime = addMinutes(currentTime, item.duration);
    currentTime = item.endTime;
  });

  day.endTime = currentTime;
}
```

#### Автоматический пересчет времени

После добавления события система:

1. **Вставляет событие в расписание дня**
2. **Сдвигает следующие элементы**
3. **Пересчитывает время окончания дня**
4. **Проверяет пересечения**

```javascript
function insertEvent(event, day) {
  // 1. Найти позицию вставки
  const insertIndex = findInsertPosition(event.startTime, day.items);

  // 2. Вставить событие
  day.items.splice(insertIndex, 0, event);

  // 3. Пересчитать время следующих элементов
  for (let i = insertIndex + 1; i < day.items.length; i++) {
    const prevEnd = day.items[i - 1].endTime;
    day.items[i].startTime = prevEnd;
    day.items[i].endTime = addMinutes(prevEnd, day.items[i].duration);
  }

  // 4. Обновить время окончания дня
  day.endTime = day.items[day.items.length - 1].endTime;

  return day;
}
```

```javascript
function validateAthlete(athlete) {
  const errors = [];

  // Обязательные поля
  if (!athlete.lastName) {
    errors.push("Фамилия обязательна");
  }
  if (!athlete.firstName) {
    errors.push("Имя обязательно");
  }
  if (!athlete.birthDate) {
    errors.push("Дата рождения обязательна");
  }

  // Формат даты
  if (!isValidDate(athlete.birthDate)) {
    errors.push("Неверный формат даты рождения");
  }

  // Возраст
  const age = calculateAge(athlete.birthDate);
  if (age < 6 || age > 30) {
    errors.push("Возраст вне допустимого диапазона (6-30 лет)");
  }

  // Дубликаты
  if (athleteExists(athlete.lastName, athlete.firstName, athlete.birthDate)) {
    errors.push("Спортсмен с таким ФИО и датой рождения уже существует");
  }

  return errors;
}
```

```javascript
function checkConflictOfInterest(judge, athletes) {
  const conflicts = [];

  // Проверка: судья не тренер участника
  athletes.forEach(athlete => {
    if (athlete.coach === judge.fullName) {
      conflicts.push({
        type: 'COACH',
        message: `Судья ${judge.fullName} является тренером ${athlete.fullName}`
      });
    }
  });

  // Проверка: судья из того же клуба
  athletes.forEach(athlete => {
    if (athlete.club === judge.club) {
      conflicts.push({
        type: 'SAME_CLUB',
        message: `Судья ${judge.fullName} из того же клуба "${judge.club}"`
      });
    }
  });

  return conflicts;
}
```

```javascript
function checkJudgeQualification(judge, competitionLevel) {
```

**Логика обработки оценок:**

```javascript
// Валидация и расчёт итогового результата
function processScores(athleteId, performanceId) {
  const scores = {
    D: getScoresFromBrigade('D', performanceId),
    E: getScoresFromBrigade('E', performanceId),
    A: getScoresFromBrigade('A', performanceId),
    time: getTimekeeperData(performanceId),
    line: getLineJudgeData(performanceId)
  };

  // Проверка наличия всех оценок
  const validation = {
    D_complete: scores.D.length === 4 && scores.D.every(s => s.submitted),
    E_complete: scores.E.length === 4 && scores.E.every(s => s.submitted),
    A_complete: scores.A.length === 4 && scores.A.every(s => s.submitted),
    time_complete: scores.time !== null,
    line_complete: scores.line !== null
  };

  if (!Object.values(validation).every(v => v === true)) {
    return {
      status: 'incomplete',
      missing: Object.keys(validation).filter(k => !validation[k]),
      message: 'Не все оценки получены'
    };
  }

  // Расчёт DB (Body Difficulty) - среднее арифметическое
  const DB_scores = scores.D.map(s => s.DB);
  const DB_avg = DB_scores.reduce((a, b) => a + b, 0) / DB_scores.length;
  const DB_final = Math.round(DB_avg * 100) / 100; // округление до 0.01

  // Расчёт DA (Apparatus Difficulty) - консенсус
  const DA_scores = scores.D.map(s => s.DA);
  const DA_unique = [...new Set(DA_scores)];

  let DA_final;
  if (DA_unique.length === 1) {
    // Все судьи согласны
    DA_final = DA_unique[0];
  } else {
    // Есть разногласия - требуется консенсус
    return {
      status: 'requires_consensus',
      brigade: 'D',
      scores: DA_scores,
      message: 'Требуется согласование оценок DA'
    };
  }

  const D_total = DB_final + DA_final;

  // Расчёт E - отбрасываем максимум и минимум, среднее из оставшихся
  const E_deductions = scores.E.map(s => s.deductions).sort((a, b) => a - b);
  E_deductions.shift(); // убираем минимум
  E_deductions.pop();   // убираем максимум
  const E_avg = E_deductions.reduce((a, b) => a + b, 0) / E_deductions.length;
  const E_deduction_final = Math.round(E_avg * 100) / 100;

  // Расчёт A - отбрасываем максимум и минимум, среднее из оставшихся
  const A_deductions = scores.A.map(s => s.deductions).sort((a, b) => a - b);
  A_deductions.shift();
  A_deductions.pop();
  const A_avg = A_deductions.reduce((a, b) => a + b, 0) / A_deductions.length;
  const A_deduction_final = Math.round(A_avg * 100) / 100;

  // Расчёт E (исполнение)
  const E_score = 10.0 - A_deduction_final - E_deduction_final;
  const E_final = Math.round(E_score * 100) / 100;

  // Штрафы
  let penalties = 0;

  // Штраф за время (если выступление > 1:30)
  if (scores.time.duration > 90) {
    const overtime = scores.time.duration - 90;
    penalties += Math.ceil(overtime / 5) * 0.05; // 0.05 за каждые 5 секунд
  }

  // Штрафы линейных судей (выходы за ковёр)
  penalties += scores.line.out_of_bounds * 0.30; // 0.30 за каждый выход

  penalties = Math.round(penalties * 100) / 100;

  // ИТОГОВАЯ ОЦЕНКА
  const final_score = D_total + E_final - penalties;
  const final_result = Math.round(final_score * 100) / 100;

  return {
    status: 'complete',
    breakdown: {
      D: {
        DB: DB_final,
        DA: DA_final,
        total: D_total
      },
      E: {
        A_deduction: A_deduction_final,
        E_deduction: E_deduction_final,
        score: E_final
      },
      penalties: {
        time: scores.time.penalty || 0,
        line: penalties - (scores.time.penalty || 0),
        total: penalties
      },
      final: final_result
    },
    timestamp: new Date().toISOString()
  };
}
```

## 7. РОЛИ И ПРАВА ДОСТУПА

**Описание:**
Система поддерживает ролевую модель доступа (RBAC) для разграничения прав различных пользователей.

**Роли в системе:**

| Роль | Описание | Права доступа |
|------|----------|---------------|
| **Администратор** | Полный доступ ко всем функциям | Создание соревнований, управление пользователями, настройка системы |
| **Главный судья** | Управление судейской коллегией | Назначение судей, разрешение конфликтов, утверждение результатов |
| **Главный секретарь** | Управление протоколами и документацией | Приём оценок, формирование протоколов, экспорт данных |
| **Судья бригады D** | Оценка трудности | Выставление оценок DB и DA |
| **Судья бригады E** | Оценка исполнения | Выставление сбавок за исполнение |
| **Судья бригады A** | Оценка артистизма | Выставление сбавок за артистизм |
| **Хронометрист** | Контроль времени | Фиксация времени выступлений |
| **Линейный судья** | Контроль выходов | Фиксация выходов за ковёр |
| **Координатор потока** | Управление расписанием потока | Запуск/остановка выступлений, управление очерёдностью |
| **Представитель клуба** | Просмотр результатов своих спортсменов | Только чтение, протоколы своего клуба |
| **Зритель** | Просмотр результатов | Только чтение общих результатов |

```javascript
// Проверка прав доступа
function hasPermission(user, permission) {
  const allowedRoles = PERMISSIONS[permission];

  if (!allowedRoles) {
    return false; // если разрешение не определено - запрещаем
  }

  if (allowedRoles.includes('*')) {
    return true; // доступно всем
  }

  return allowedRoles.includes(user.role);
}

// Middleware для проверки прав
function requirePermission(permission) {
  return (req, res, next) => {
    const user = req.user; // получаем из сессии/токена

    if (!user) {
      return res.status(401).json({ error: 'Не авторизован' });
    }

    if (!hasPermission(user, permission)) {
      return res.status(403).json({
        error: 'Недостаточно прав',
        required: permission,
        your_role: user.role
      });
    }

    next();
  };
}
```

```javascript
// Подключение к WebSocket
import io from 'socket.io-client';

class WebSocketService {
  constructor() {
    this.socket = null;
    this.listeners = {};
  }

  connect(serverUrl, userData) {
    this.socket = io(serverUrl, {
      reconnection: true,
      reconnectionDelay: 1000,
      reconnectionAttempts: 10
    });

    // Регистрация при подключении
    this.socket.on('connect', () => {
      console.log('Connected to WebSocket server');
      this.socket.emit('register', userData);
    });

    // Обработка переподключения
    this.socket.on('reconnect', (attemptNumber) => {
      console.log(`Reconnected after ${attemptNumber} attempts`);
      this.socket.emit('register', userData);
    });

    // Обработка ошибок
    this.socket.on('error', (error) => {
      console.error('WebSocket error:', error);
      this.trigger('error', error);
    });

    // Обработка отключения
    this.socket.on('disconnect', (reason) => {
      console.log('Disconnected:', reason);
      this.trigger('disconnected', reason);
    });

    return this;
  }

  // Подписка на события
  on(event, callback) {
    if (!this.listeners[event]) {
      this.listeners[event] = [];
    }
    this.listeners[event].push(callback);

    // Подписываемся на событие socket.io
    this.socket.on(event, callback);
  }

  // Отписка от события
  off(event, callback) {
    if (this.listeners[event]) {
      this.listeners[event] = this.listeners[event].filter(cb => cb !== callback);
    }
    this.socket.off(event, callback);
  }

  // Отправка события
  emit(event, data) {
    if (this.socket && this.socket.connected) {
      this.socket.emit(event, data);
    } else {
      console.error('Socket not connected');
    }
  }

  // Триггер локальных событий
  trigger(event, data) {
    if (this.listeners[event]) {
      this.listeners[event].forEach(callback => callback(data));
    }
  }

  disconnect() {
    if (this.socket) {
      this.socket.disconnect();
    }
  }
}
```

```javascript
class CloudSyncService {
  constructor(config) {
    this.cloudApiUrl = config.cloudApiUrl;
    this.syncInterval = config.syncInterval || 300000; // 5 минут
    this.enabled = config.enabled || false;
    this.lastSync = null;
    this.syncQueue = [];

    if (!this.enabled) {
      console.log('Cloud sync is disabled');
      return;
    }

    console.log('Starting cloud sync service');
    this.syncInterval = setInterval(() => {
      this.sync();
    }, this.syncInterval);

    this.sync();

  // Синхронизация данных

    try {

      // 1. Проверяем доступность облака
      const isOnline = await this.checkCloudAvailability();
      if (!isOnline) {
        console.log('Cloud is not available, skipping sync');
        return;
      }

      // 2. Отправляем локальные изменения в облако
      await this.pushLocalChanges();

      // 3. Получаем обновления из облака (если есть)
      await this.pullCloudUpdates();

      // 4. Обновляем метку последней синхронизации
      this.lastSync = new Date();

      console.log('Cloud sync completed successfully');

    } catch (error) {
      console.error('Cloud sync failed:', error);
      // Продолжаем работу в офлайн-режиме
    }
  }

  // Проверка доступности облака
  async checkCloudAvailability() {
    try {
      const response = await fetch(`${this.cloudApiUrl}/health`, {
        method: 'GET',
        timeout: 5000
      });
      return response.ok;
    } catch (error) {
      return false;
    }
  }

  // Отправка локальных изменений в облако
  async pushLocalChanges() {
    // Получаем все изменения с момента последней синхронизации
    const changes = await db.query(`
      SELECT * FROM sync_queue
      WHERE synced = false
      ORDER BY created_at ASC
    `);

    if (changes.rows.length === 0) {
      console.log('No local changes to push');
      return;
    }

    console.log(`Pushing ${changes.rows.length} changes to cloud`);

    // Отправляем батчами по 100 записей
    const batchSize = 100;
    for (let i = 0; i < changes.rows.length; i += batchSize) {
      const batch = changes.rows.slice(i, i + batchSize);

      try {
        const response = await fetch(`${this.cloudApiUrl}/sync/push`, {
          method: 'POST',
          headers: {
            'Content-Type': 'application/json',
            'Authorization': `Bearer ${this.getApiKey()}`
          },
          body: JSON.stringify({ changes: batch })
        });

        if (response.ok) {
          // Помечаем как синхронизированные
          const ids = batch.map(c => c.id);
          await db.query(`
            UPDATE sync_queue
            SET synced = true, synced_at = NOW()
            WHERE id = ANY($1)
          `, [ids]);
        } else {
          console.error('Failed to push batch:', response.statusText);
        }
      } catch (error) {
        console.error('Error pushing batch:', error);
      }
    }
  }

  // Получение обновлений из облака
  async pullCloudUpdates() {
    try {
      const response = await fetch(`${this.cloudApiUrl}/sync/pull`, {
        method: 'POST',
        headers: {
          'Content-Type': 'application/json',
          'Authorization': `Bearer ${this.getApiKey()}`
        },
        body: JSON.stringify({
          last_sync: this.lastSync ? this.lastSync.toISOString() : null
        })
      });

      if (!response.ok) {
        throw new Error('Failed to pull updates from cloud');
      }

      const { updates } = await response.json();

      if (updates && updates.length > 0) {
        console.log(`Received ${updates.length} updates from cloud`);

        // Применяем обновления
        for (const update of updates) {
          await this.applyUpdate(update);
        }
      }

    } catch (error) {
      console.error('Error pulling updates:', error);
    }
  }

  // Применение обновления из облака
  async applyUpdate(update) {
    const { entity_type, entity_id, action, data } = update;

    switch (action) {
      case 'INSERT':
        await db.query(`
          INSERT INTO ${entity_type}
          VALUES ${this.buildInsertValues(data)}
          ON CONFLICT DO NOTHING
        `);
        break;

      case 'UPDATE':
        await db.query(`
          UPDATE ${entity_type}
          SET ${this.buildUpdateSet(data)}
          WHERE id = $1
        `, [entity_id]);
        break;

      case 'DELETE':
        await db.query(`
          DELETE FROM ${entity_type}
          WHERE id = $1
        `, [entity_id]);
        break;
    }
  }

  // Добавление изменения в очередь синхронизации
  async queueChange(entityType, entityId, action, data) {

      INSERT INTO sync_queue (entity_type, entity_id, action, data, created_at, synced)

      clearInterval(this.syncInterval);
    }
  }
```

```javascript
class DatabaseService {
  constructor() {
    this.primaryDb = null; // PostgreSQL
    this.fallbackDb = null; // SQLite
    this.isOnline = true;
  }

  async connect() {
    try {
      // Пытаемся подключиться к PostgreSQL
      this.primaryDb = await connectPostgreSQL();
      this.isOnline = true;
      console.log('Connected to PostgreSQL');
    } catch (error) {
      console.error('Failed to connect to PostgreSQL, using SQLite fallback');
      this.fallbackDb = await connectSQLite('./data/fallback.db');
      this.isOnline = false;
    }
  }

  async query(sql, params) {
    try {
      if (this.isOnline && this.primaryDb) {
        return await this.primaryDb.query(sql, params);
      } else if (this.fallbackDb) {
        return await this.fallbackDb.query(sql, params);
      } else {
        throw new Error('No database connection available');
      }
    } catch (error) {
      // Если ошибка PostgreSQL, переключаемся на SQLite
      if (this.isOnline && error.code === 'ECONNREFUSED') {
        console.error('PostgreSQL connection lost, switching to SQLite');
        this.isOnline = false;
        this.fallbackDb = await connectSQLite('./data/fallback.db');
        return await this.fallbackDb.query(sql, params);
      }
      throw error;
    }
  }

  // Восстановление соединения с PostgreSQL
  async reconnect() {
    setInterval(async () => {
      if (!this.isOnline) {
        try {
          this.primaryDb = await connectPostgreSQL();
          console.log('Reconnected to PostgreSQL');

          // Синхронизируем данные из SQLite в PostgreSQL
          await this.syncSQLiteToPostgreSQL();

          this.isOnline = true;

          // Закрываем SQLite
          if (this.fallbackDb) {
            await this.fallbackDb.close();
            this.fallbackDb = null;
          }
        } catch (error) {
          // Продолжаем работать на SQLite
          console.log('Still offline, using SQLite');
        }
      }
    }, 30000); // проверяем каждые 30 секунд
  }

  // Синхронизация SQLite → PostgreSQL
  async syncSQLiteToPostgreSQL() {
    console.log('Syncing SQLite data to PostgreSQL...');

    // Получаем все изменения из SQLite
    const changes = await this.fallbackDb.query(`
      SELECT * FROM sync_queue WHERE synced = 0
    `);

    // Применяем изменения в PostgreSQL
    for (const change of changes) {
      try {
        await this.primaryDb.query(change.sql, change.params);

        // Помечаем как синхронизированные
        await this.fallbackDb.query(`
          UPDATE sync_queue SET synced = 1 WHERE id = ?
        `, [change.id]);
      } catch (error) {
        console.error('Error syncing change:', error);
      }
    }

    console.log('SQLite sync completed');
  }
}
```

#### 10.1.1. Автоматическая жеребьевка

4. **Ручная жеребьевка** - ручное распределение порядка

```javascript
// Автоматическая жеребьевка с учётом клубов
function performDraw(athletes, options) {
  const {
    separateClubs = true,
    minClubDistance = 3,
    considerRating = false,
    seed = null
  } = options;

  // Устанавливаем seed для воспроизводимости
  if (seed) {
    Math.seedrandom(seed);
  }

  let sortedAthletes = [...athletes];

  // Если учитываем рейтинг, сортируем
  if (considerRating) {
    sortedAthletes.sort((a, b) => a.rating - b.rating);
  } else {
    // Случайное перемешивание
    sortedAthletes = shuffle(sortedAthletes);
  }

  // Группируем по клубам
  const clubGroups = {};
  sortedAthletes.forEach(athlete => {
    if (!clubGroups[athlete.club]) {
      clubGroups[athlete.club] = [];
    }
    clubGroups[athlete.club].push(athlete);
  });

  // Распределяем участников с учётом разнесения клубов
  const drawOrder = [];
  const clubLastPosition = {}; // последняя позиция спортсмена из каждого клуба

  if (separateClubs) {
    // Создаём очередь клубов
    const clubQueue = Object.keys(clubGroups).sort(() => Math.random() - 0.5);

    while (drawOrder.length < sortedAthletes.length) {
      let placed = false;

      // Пытаемся разместить спортсмена из каждого клуба
      for (const club of clubQueue) {
        if (clubGroups[club].length === 0) continue;

        const currentPosition = drawOrder.length + 1;
        const lastPos = clubLastPosition[club] || 0;

        // Проверяем минимальную дистанцию
        if (currentPosition - lastPos >= minClubDistance || lastPos === 0) {
          const athlete = clubGroups[club].shift();
          drawOrder.push({
            ...athlete,
            start_number: currentPosition,
            draw_position: currentPosition
          });
          clubLastPosition[club] = currentPosition;
          placed = true;
        }
      }

      // Если не смогли разместить с учётом дистанции, берём любого
      if (!placed) {
        for (const club of clubQueue) {
          if (clubGroups[club].length > 0) {
            const athlete = clubGroups[club].shift();
            const currentPosition = drawOrder.length + 1;
            drawOrder.push({
              ...athlete,
              start_number: currentPosition,
              draw_position: currentPosition
            });
            clubLastPosition[club] = currentPosition;
            break;
          }
        }
      }
    }
  } else {
    // Простая случайная жеребьевка
    sortedAthletes.forEach((athlete, index) => {
      drawOrder.push({
        ...athlete,
        start_number: index + 1,
        draw_position: index + 1
      });
    });
  }

  return {
    draw_order: drawOrder,
    seed: seed || Math.random().toString(36).substring(7),
    timestamp: new Date().toISOString(),
    statistics: calculateDrawStatistics(drawOrder)
  };
}

// Статистика жеребьевки
function calculateDrawStatistics(drawOrder) {
  const clubDistances = {};

  drawOrder.forEach((athlete, index) => {
    if (!clubDistances[athlete.club]) {
      clubDistances[athlete.club] = {
        positions: [],
        minDistance: Infinity
      };
    }
    clubDistances[athlete.club].positions.push(index + 1);
  });

  // Вычисляем минимальные дистанции между спортсменами одного клуба
  Object.keys(clubDistances).forEach(club => {
    const positions = clubDistances[club].positions;
    if (positions.length > 1) {
      for (let i = 1; i < positions.length; i++) {
        const distance = positions[i] - positions[i - 1];
        clubDistances[club].minDistance = Math.min(
          clubDistances[club].minDistance,
          distance
        );
      }
    } else {
      clubDistances[club].minDistance = null;
    }
  });

  return {
    total_athletes: drawOrder.length,
    clubs: Object.keys(clubDistances).length,
    club_distances: clubDistances
  };
}
```

```javascript
      if (score.DB < 0 || score.DB > 10) {
        errors.push('DB должен быть в диапазоне 0-10');
      }
      if (score.DA < 0 || score.DA > 5) {
        errors.push('DA должен быть в диапазоне 0-5');
      }
    } else if (this.brigade === 'E' || this.brigade === 'A') {
      // Валидация для бригад E и A
      if (score.deductions < 0 || score.deductions > 10) {
        errors.push('Сбавки должны быть в диапазоне 0-10');
      }
    }

    return errors;
  }

  // Отправка оценки
  async submitScore(score) {
    // Валидация
    const errors = this.validateScore(score);
    if (errors.length > 0) {
      throw new Error(errors.join(', '));
    }

    // Отправка через WebSocket
    await wsService.emit('submit_score', {
      performance_id: this.currentPerformance.id,
      judge_id: this.judgeId,
      brigade: this.brigade,
      score: score,
      timestamp: new Date().toISOString()
    });

    this.onScoreSubmit();
  }
}
```

```javascript
  const mean = values.reduce((a, b) => a + b, 0) / values.length;

    judges: scores.map((score, index) => ({
      judge: score.judge_name,
      value: values[index],
      deviation: deviations[index],

    }))
  };
```

### 10.4. Утверждение оценок

#### 10.4.1. Утверждение главным судьёй

**Процесс утверждения:**

```javascript
// Процесс утверждения оценок главным судьёй
class ChiefJudgeApproval {
  constructor(performanceId) {
    this.performanceId = performanceId;
    this.scores = null;
    this.refereeRecommendation = null;
    this.discrepancies = [];
  }

  async loadScores() {
    this.scores = await getAllScores(this.performanceId);
    this.refereeRecommendation = await getRefereeRecommendation(this.performanceId);
    this.discrepancies = await analyzeDiscrepancies(this.scores);
  }

  async approveScores(chiefJudgeId, decision) {
    const approval = {
      performance_id: this.performanceId,
      chief_judge_id: chiefJudgeId,
      decision: decision, // 'approve', 'request_consensus', 'adjust'
      adjustments: decision.adjustments || null,
      comment: decision.comment || null,
      timestamp: new Date().toISOString()
    };

    if (decision.type === 'approve') {
      // Утверждаем оценки как есть
      await db.query(`
        UPDATE performances
        SET status = 'approved',
            approved_by = $1,
            approved_at = NOW()
        WHERE id = $2
      `, [chiefJudgeId, this.performanceId]);

      // Публикуем результаты
      await publishResults(this.performanceId);

    } else if (decision.type === 'request_consensus') {
      // Запрашиваем консенсус у бригады
      await requestConsensus(
        this.performanceId,
        decision.brigade,
        decision.parameter
      );

    } else if (decision.type === 'adjust') {
      // Главный судья вносит корректировки
      await applyChiefJudgeAdjustments(
        this.performanceId,
        decision.adjustments,
        approval
      );
    }

    // Сохраняем решение
    await db.query(`
      INSERT INTO chief_judge_decisions
      (performance_id, chief_judge_id, decision_type, adjustments, comment, created_at)
      VALUES ($1, $2, $3, $4, $5, NOW())
    `, [
      this.performanceId,
      chiefJudgeId,
      decision.type,
      JSON.stringify(decision.adjustments),
      decision.comment
    ]);

    return approval;
  }
}
```

## 11. РАНЖИРОВАНИЕ И ОЦЕНКИ

### 11.1. Распределение мест при совпадении оценок

**Описание:**
Система автоматически определяет места спортсменов с учётом различных правил ранжирования при совпадении итоговых оценок.

#### 11.1.1. Простое деление места

**Правило:** При совпадении оценок спортсменам присваивается одинаковое место, следующее место не пропускается.

**Пример:** 1-1-2-3-4

```javascript
// Простое деление места (1-1-2)
function rankAthletesSimpleDivision(athletes) {
  // Сортируем по убыванию оценки
  const sorted = [...athletes].sort((a, b) => b.final_score - a.final_score);

  let currentRank = 1;
  let prevScore = null;

  return sorted.map((athlete, index) => {
    // Если оценка совпадает с предыдущей, даём то же место
    if (prevScore !== null && Math.abs(athlete.final_score - prevScore) < 0.001) {
      return {
        ...athlete,
        rank: currentRank,
        shared_rank: true
      };
    }

    // Иначе - следующее место (без пропусков)
    currentRank = index + 1;
    prevScore = athlete.final_score;

    return {
      ...athlete,
      rank: currentRank,
      shared_rank: false
    };
  });
}

// Результат:
// Иванова - 18.50 -> 1 место
// Петрова - 18.50 -> 1 место (разделенное)
// Сидорова - 18.30 -> 2 место
// Козлова - 18.10 -> 3 место
```

#### 11.1.2. Деление места с пропуском

**Правило:** При совпадении оценок спортсменам присваивается одинаковое место, следующее место пропускается.

**Пример:** 1-1-3-4-5

```javascript
// Деление места с пропуском (1-1-3)
function rankAthletesWithSkip(athletes) {
  const sorted = [...athletes].sort((a, b) => b.final_score - a.final_score);

  let currentRank = 1;
  let prevScore = null;
  let sameScoreCount = 0;

  return sorted.map((athlete, index) => {
    if (prevScore !== null && Math.abs(athlete.final_score - prevScore) < 0.001) {
      // Та же оценка - то же место
      sameScoreCount++;
      return {
        ...athlete,
        rank: currentRank,
        shared_rank: true
      };
    } else {
      // Новая оценка - следующее место с учетом пропусков
      currentRank = index + 1;
      prevScore = athlete.final_score;
      sameScoreCount = 0;

      return {
        ...athlete,
        rank: currentRank,
        shared_rank: false
      };
    }
  });
}

// Результат:
// Иванова - 18.50 -> 1 место
// Петрова - 18.50 -> 1 место (разделенное)
// Сидорова - 18.30 -> 3 место (2 место пропущено)
// Козлова - 18.10 -> 4 место
```

#### 11.1.3. Тай-брейк по компонентам оценки (E-A-D)

**Правило:** При совпадении итоговой оценки проверяем компоненты в порядке: E (исполнение) → A (артистизм) → D (трудность).

```javascript
// Тай-брейк по компонентам E-A-D
function rankAthletesWithTiebreak(athletes) {
  const sorted = [...athletes].sort((a, b) => {
    // Сначала сравниваем итоговую оценку
    const scoreDiff = b.final_score - a.final_score;
    if (Math.abs(scoreDiff) >= 0.001) {
      return scoreDiff;
    }

    // Если итоговые оценки равны, сравниваем E (исполнение)
    const eDiff = b.E_score - a.E_score;
    if (Math.abs(eDiff) >= 0.001) {
      return eDiff;
    }

    // Если E равны, сравниваем A (артистизм)
    // Меньше сбавок = лучше
    const aDiff = a.A_deduction - b.A_deduction;
    if (Math.abs(aDiff) >= 0.001) {
      return aDiff;
    }

    // Если A равны, сравниваем D (трудность)
    const dDiff = b.D_score - a.D_score;
    return dDiff;
  });

  return sorted.map((athlete, index) => ({
    ...athlete,
    rank: index + 1,
    shared_rank: false
  }));
}

// Пример:
// Иванова: Итого 18.50 (D: 6.5, E: 8.7, A: -0.3) -> 1 место
// Петрова: Итого 18.50 (D: 6.3, E: 8.7, A: -0.3) -> 2 место (меньше D)
// Сидорова: Итого 18.50 (D: 6.5, E: 8.6, A: -0.2) -> 3 место (меньше E)
```

### 11.2. Расчёт оценки D для индивидуальных упражнений

**Описание:**
Система поддерживает два метода расчёта оценки D (трудность) для индивидуальных упражнений.

#### 11.2.1. Среднее арифметическое (российское правило)

**Формула:** `D = (DB1 + DB2 + DB3 + DB4) / 2`

Где:
- DB1, DB2, DB3, DB4 - оценки трудности тела от 4 судей бригады D

```javascript
// Расчёт D по российскому правилу (среднее арифметическое)
function calculateD_AverageMethod(judgeScores) {
  // judgeScores = [
  //   { judge: 'D1', DB: 3.80, DA: 2.90 },
  //   { judge: 'D2', DB: 3.80, DA: 2.90 },
  //   { judge: 'D3', DB: 3.70, DA: 2.90 },
  //   { judge: 'D4', DB: 3.80, DA: 2.90 }
  // ]

  // Вычисляем среднее DB
  const DB_sum = judgeScores.reduce((sum, s) => sum + s.DB, 0);
  const DB_average = DB_sum / judgeScores.length;
  const DB_rounded = Math.round(DB_average * 100) / 100;

  // DA - консенсус (все должны согласиться)
  const DA_values = judgeScores.map(s => s.DA);
  const DA_unique = [...new Set(DA_values)];

  if (DA_unique.length > 1) {
    throw new Error('Требуется консенсус по DA');
  }

  const DA = DA_unique[0];

  // D = DB + DA
  const D_total = DB_rounded + DA;

  return {
    DB: DB_rounded,
    DA: DA,
    D: Math.round(D_total * 100) / 100,
    method: 'average'
  };
}

// Пример:
// Судьи: DB = [3.80, 3.80, 3.70, 3.80], DA = [2.90, 2.90, 2.90, 2.90]
// DB средний = (3.80 + 3.80 + 3.70 + 3.80) / 4 = 3.775 → 3.78
// DA = 2.90 (консенсус)
// D = 3.78 + 2.90 = 6.68
```

#### 11.2.2. Сумма оценок двух бригад (международное правило FIG)

**Формула:** `D = (DB1 + DB2) / 2 + (DB3 + DB4) / 2`

Судьи делятся на две подбригады: (D1+D2) и (D3+D4).

```javascript
// Расчёт D по международному правилу FIG (две бригады)
function calculateD_TwoBrigadesMethod(judgeScores) {
  // Проверяем, что судей ровно 4
  if (judgeScores.length !== 4) {
    throw new Error('Требуется 4 судьи для метода двух бригад');
  }

  // Делим на две подбригады
  const brigade1 = [judgeScores[0], judgeScores[1]]; // D1, D2
  const brigade2 = [judgeScores[2], judgeScores[3]]; // D3, D4

  // Вычисляем среднее DB для каждой подбригады
  const DB_brigade1 = (brigade1[0].DB + brigade1[1].DB) / 2;
  const DB_brigade2 = (brigade2[0].DB + brigade2[1].DB) / 2;

  // Округляем до 0.01
  const DB1 = Math.round(DB_brigade1 * 100) / 100;
  const DB2 = Math.round(DB_brigade2 * 100) / 100;

  // Итоговый DB - среднее двух подбригад
  const DB_final = Math.round(((DB1 + DB2) / 2) * 100) / 100;

  // DA - консенсус всех судей
  const DA_values = judgeScores.map(s => s.DA);
  const DA_unique = [...new Set(DA_values)];

  if (DA_unique.length > 1) {
    throw new Error('Требуется консенсус по DA');
  }

  const DA = DA_unique[0];

  // D = DB + DA
  const D_total = DB_final + DA;

  return {
    DB_brigade1: DB1,
    DB_brigade2: DB2,
    DB: DB_final,
    DA: DA,
    D: Math.round(D_total * 100) / 100,
    method: 'two_brigades'
  };
}

// Пример:
// Судьи: DB = [3.80, 3.80, 3.70, 3.80], DA = [2.90, 2.90, 2.90, 2.90]
// Бригада 1 (D1+D2): (3.80 + 3.80) / 2 = 3.80
// Бригада 2 (D3+D4): (3.70 + 3.80) / 2 = 3.75
// DB итоговый = (3.80 + 3.75) / 2 = 3.775 → 3.78
// DA = 2.90
// D = 3.78 + 2.90 = 6.68
```

```javascript
        errors.push({ row: index + 2, errors: validationErrors });
      } else {
        athletes.push(athlete);
      }
    } catch (error) {
      errors.push({ row: index + 2, error: error.message });
    }
  });

  return { athletes, errors };
}

// Жеребьёвка
function performDrawSimple(athletes) {
  // Случайное перемешивание
  const shuffled = shuffle([...athletes]);

  // Присваиваем номера
  return shuffled.map((athlete, index) => ({
    ...athlete,
    number: index + 1
  }));
}

// Сдвиг участника вверх/вниз
function moveAthlete(athletes, athleteNumber, direction) {
  const index = athletes.findIndex(a => a.number === athleteNumber);

  if (index === -1) {
    throw new Error('Участник не найден');
  }

  if (direction === 'up' && index > 0) {
    // Меняем местами с предыдущим
    [athletes[index - 1], athletes[index]] = [athletes[index], athletes[index - 1]];

    // Обновляем номера
    athletes[index - 1].number = index;
    athletes[index].number = index + 1;
  } else if (direction === 'down' && index < athletes.length - 1) {
    // Меняем местами со следующим
    [athletes[index], athletes[index + 1]] = [athletes[index + 1], athletes[index]];

    // Обновляем номера
    athletes[index].number = index + 1;
    athletes[index + 1].number = index + 2;
  }

  return athletes;
}
```

```javascript
// Автоматическое распределение по потокам
function distributeAthletesToStreams(athletes, config) {
  const {
    athletesPerStream = 20,
    minAthletesPerStream = 15
  } = config;

  const streams = [];
  let currentStream = [];
  let streamNumber = 1;

  athletes.forEach((athlete, index) => {
    currentStream.push(athlete);

    // Если набрали нужное количество, создаём поток
    if (currentStream.length >= athletesPerStream) {
      streams.push({
        number: streamNumber,
        athletes: currentStream,
        count: currentStream.length
      });

      currentStream = [];
      streamNumber++;
    }
  });

  // Обрабатываем остаток
  if (currentStream.length > 0) {
    if (currentStream.length < minAthletesPerStream && streams.length > 0) {
      // Объединяем с последним потоком
      streams[streams.length - 1].athletes.push(...currentStream);
      streams[streams.length - 1].count = streams[streams.length - 1].athletes.length;
    } else {
      // Создаём отдельный поток
      streams.push({
        number: streamNumber,
        athletes: currentStream,
        count: currentStream.length
      });
    }
  }

  return streams;
}
```

```javascript
// Автоматический пересчёт времени при изменении времени начала
function recalculateSchedule(day, newStartTime) {
  const events = day.events; // все события дня
  let currentTime = parseTime(newStartTime);

  const updatedEvents = events.map(event => {
    const startTime = currentTime;

    // Рассчитываем продолжительность события
    let duration;
    if (event.type === 'group') {
      // Для группы: количество участников * время на одного
      const athleteCount = event.athletes.length;
      const timePerAthlete = 3; // 3 минуты (90 сек выступление + 30 сек разминка + 60 сек переход)
      duration = athleteCount * timePerAthlete;
    } else {
      // Для события: указанная продолжительность
      duration = event.duration_minutes;
    }

    // Вычисляем время окончания
    const endTime = addMinutes(startTime, duration);

    // Обновляем текущее время для следующего события
    currentTime = endTime;

    return {
      ...event,
      start_time: formatTime(startTime),
      end_time: formatTime(endTime),
      duration_minutes: duration
    };
  });

  // Время окончания дня
  const dayEndTime = currentTime;

  return {
    ...day,
    start_time: newStartTime,
    end_time: formatTime(dayEndTime),
    events: updatedEvents
  };
}
```

```javascript
// Парсинг элемента из строки (например, "J 180° A")
function parseElement(elementString) {
  const patterns = {
    jump: /^J\s*(\d+)°?\s*([A-Z])?$/i,
    balance: /^B\s*(\d+)°?\s*([A-Z])?$/i,
    rotation: /^R\s*(\d+)°?\s*([A-Z])?$/i,
    wave: /^W\s*([A-Z])?$/i
  };

  for (const [type, pattern] of Object.entries(patterns)) {
    const match = elementString.match(pattern);

    if (match) {
      const degrees = match[1] ? parseInt(match[1]) : null;
      const difficulty = match[2] || '';

      return {
        type: type,
        degrees: degrees,
        difficulty: difficulty,
        value: calculateElementValue(type, degrees, difficulty)
      };
    }
  }

  return null;
}

// Расчет стоимости элемента
function calculateElementValue(type, degrees, difficulty) {
  const baseValues = {
    jump: {
      0: 0.10,
      180: 0.30,
      360: 0.50,
      540: 0.70
    },
    balance: {
      0: 0.10,
      180: 0.30,
      360: 0.50,
      540: 0.60,
      720: 0.70
    },
    rotation: {
      180: 0.10,
      360: 0.30,
      540: 0.50,
      720: 0.70,
      1080: 0.90
    }
  };

  let base = baseValues[type]?.[degrees] || 0.10;

  // Дополнительная стоимость за сложность
  const difficultyBonus = {
    'A': 0.10,
    'B': 0.20,
    'C': 0.30,
    'D': 0.40
  };

  return base + (difficultyBonus[difficulty] || 0);
}

// Проверка требований FIG
function validateElements(elements) {
  const counts = {
    jump: elements.filter(e => e.type === 'jump').length,
    balance: elements.filter(e => e.type === 'balance').length,
    rotation: elements.filter(e => e.type === 'rotation').length
  };

  const errors = [];

  if (counts.jump < 2) {
    errors.push('Недостаточно прыжков (мин. 2)');
  }
  if (counts.balance < 2) {
    errors.push('Недостаточно равновесий (мин. 2)');
  }
  if (counts.rotation < 2) {
    errors.push('Недостаточно поворотов (мин. 2)');
  }
  if (elements.length > 9) {
    errors.push('Превышено максимальное количество элементов (9)');
  }

  return {
    valid: errors.length === 0,
    errors: errors,
    counts: counts
  };
}
```

```javascript
// Расчет оценки трудности предмета (DA)
function calculateDA(risks, masteryElements) {
  // Риски (максимум 4 элемента)
  const riskScore = risks
    .slice(0, 4)
    .reduce((sum, risk) => sum + risk.value, 0);

  // Мастерство владения предметом
  const totalMasteryElements = Object.values(masteryElements)
    .reduce((sum, count) => sum + count, 0);

  // Каждый элемент = 0.05 балла, максимум 1.00
  const masteryScore = Math.min(totalMasteryElements * 0.05, 1.00);

  return {
    riskScore: Math.round(riskScore * 100) / 100,
    masteryScore: Math.round(masteryScore * 100) / 100,
    total: Math.round((riskScore + masteryScore) * 100) / 100
  };
}
```

```javascript
function validateBalancedScore(score, brigade) {
  const warnings = [];
  const errors = [];

  if (brigade === 'D') {
    const { DB, DA } = score;

    // Проверка разумных диапазонов
    if (DB < 0 || DB > 10) {
      errors.push('DB должно быть в диапазоне 0-10');
    }
    if (DA < 0 || DA > 5) {
      errors.push('DA должно быть в диапазоне 0-5');
    }

    // Предупреждения о нестандартных значениях
    if (DB > 6) {
      warnings.push('Очень высокая оценка DB (>6.0). Проверьте корректность.');
    }
    if (DA > 4) {
      warnings.push('Очень высокая оценка DA (>4.0). Проверьте корректность.');
    }
  }

  if (brigade === 'E' || brigade === 'A') {
    const deductions = score.deductions;

    // Проверка диапазона сбавок
    if (deductions < 0 || deductions > 10) {
      errors.push('Сбавки должны быть в диапазоне 0-10');
    }

    // Предупреждения
    if (deductions > 5) {
      warnings.push('Очень большие сбавки (>5.0). Проверьте корректность.');
    }
  }

  return {
    valid: errors.length === 0,
    errors: errors,
    warnings: warnings
  };
```

```javascript
// Автосохранение оценки при вводе
class JudgeScoringAutosave {
  constructor(judgeId, brigade) {
    this.judgeId = judgeId;
    this.brigade = brigade;
    this.autosaveInterval = null;
  }

  startAutosave(performanceId) {
    // Сохраняем каждые 5 секунд
    this.autosaveInterval = setInterval(() => {
      const currentScore = this.getCurrentScore();

      if (currentScore) {
        this.saveDraft(performanceId, currentScore);
      }
    }, 5000);
  }

  stopAutosave() {
    if (this.autosaveInterval) {
      clearInterval(this.autosaveInterval);
    }
  }

  saveDraft(performanceId, score) {
    // Сохраняем в локальное хранилище
    localStorage.setItem(`draft_${performanceId}_${this.judgeId}`, JSON.stringify({
      score: score,
      timestamp: new Date().toISOString()
    }));
  }

  loadDraft(performanceId) {
    const draft = localStorage.getItem(`draft_${performanceId}_${this.judgeId}`);
    return draft ? JSON.parse(draft) : null;
  }

  clearDraft(performanceId) {
    localStorage.removeItem(`draft_${performanceId}_${this.judgeId}`);
  }

  getCurrentScore() {
    // Получение текущего значения оценки из интерфейса
```

```javascript
function showRestoreDialog(draft) {
  const timestamp = new Date(draft.timestamp);
  const timeAgo = getTimeAgo(timestamp);

  // Диалог восстановления
  const confirmed = confirm(
    `Найден несохраненный черновик (${timeAgo}).\n` +
    `Восстановить оценку?`
  );

  if (confirmed) {
    // Восстанавливаем оценку в интерфейсе
    restoreScoreToUI(draft.score);
  }
}

function getTimeAgo(timestamp) {
  const now = new Date();
  const diff = now - timestamp;
  const minutes = Math.floor(diff / 60000);

  if (minutes < 1) return 'менее минуты назад';
  if (minutes === 1) return '1 минуту назад';
  if (minutes < 5) return `${minutes} минуты назад`;
  return `${minutes} минут назад`;
}
```

**Индикатор автосохранения:**

В интерфейсе каждого судьи отображается индикатор автосохранения:

```
┌────────────────────────────────────────────────────────┐
│  СУДЬЯ D1 • Иванова М.П.     💾 Сохранено    [Выйти]  │
└────────────────────────────────────────────────────────┘
```

Состояния индикатора:
- 💾 Сохранено - черновик успешно сохранен
- ⏳ Сохранение... - идет процесс сохранения
- ⚠️ Ошибка сохранения - не удалось сохранить (проблемы с соединением)

### 14.6. Сравнение типов интерфейсов

**Таблица сравнения:**

| Характеристика | Расширенный | С минимизацией ошибок | Упрощенный |
|---|---|---|---|
| **Детализация** | Полная | Средняя | Минимальная |
| **Время ввода оценки** | 2-3 минуты | 30-60 секунд | 10-20 секунд |
| **Автоматические проверки** | Да (полные) | Да (базовые) | Нет |
| **Подсказки** | Да | Да | Нет |
| **Защита от ошибок** | Высокая | Средняя | Низкая |
| **Требуется обучение** | Да | Минимальное | Нет |
| **Рекомендуется для** | Национальные соревнования, эксперты | Региональные/всероссийские | Локальные соревнования |
| **Подходит для новичков** | Нет | Да | Только опытным |

**Рекомендации по выбору:**

1. **Расширенный интерфейс** - выбирайте если:
   - Проводится соревнование национального/международного уровня
   - Требуется детальная фиксация всех элементов
   - Судья имеет опыт работы с электронными системами
   - Важна полная прозрачность оценивания

2. **С минимизацией ошибок** - выбирайте если:
   - Большинство соревнований региональные/всероссийские
   - Нужен баланс между скоростью и точностью
   - Судьи имеют разный уровень подготовки
   - Важна защита от типичных ошибок ввода

3. **Упрощенный** - выбирайте если:
   - Проводятся локальные/клубные соревнования
   - Судьи привыкли к бумажным протоколам
   - Важна максимальная скорость работы
   - Судьи - опытные эксперты, не нуждающиеся в подсказках
